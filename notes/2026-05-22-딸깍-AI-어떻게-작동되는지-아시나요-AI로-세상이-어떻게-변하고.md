# 딸깍 AI 어떻게 작동되는지 아시나요...? AI로 세상이 어떻게 변하고 있는지 보여드립니다. 하네스 딸깍 시연회

## 🧠 이해 (Understand)
- **Summary:** AI 하네스(Harness) 개발자들이 실제로 편집 도구를 만드는 과정을 보여주는 영상입니다. 하네스란 AI 에이전트들을 체계적으로 관리하고 조율하는 프레임워크로, 복잡한 작업을 여러 AI 에이전트가 협업해서 처리합니다. 영상에서는 음성 편집에서 무음 구간이 아닌 추임새('어음', '그래서' 등)를 자동으로 제거하는 도구를 실시간으로 개발하는 과정을 시연했습니다. 두 가지 접근법이 소개됩니다: 1) 상세한 인터뷰를 통해 요구사항을 정확히 파악한 후 개발하는 방식과 2) 간단한 지시로 바로 개발에 착수하는 방식. 각각 장단점이 있으며, 복잡한 프로젝트일수록 첫 번째 방식이, 간단한 작업일수록 두 번째 방식이 효과적입니다.
- **Core Message:** AI 하네스를 통해 복잡한 소프트웨어 개발도 사용자의 자연어 설명만으로 자동화할 수 있으며, 이는 개발 패러다임의 근본적 변화를 의미한다.
> 이거 쓰고서 연봉 올랐다는 피드백을 가지고 있어요
> 내가 어떤 과업을 하나 완수하는데 드는 인지적인 부하의 총량을 줄이자
> 안 될 수도 있는데 안 되면 고치면 되죠
❗ 개발자들이 200만 정도 다운로드하면 유저수가 3-4만 명 정도로 추산됨
❗ 하네스를 통해 자고 일어나면 완성된 소프트웨어가 만들어져 있는 경험을 실제로 함
❗ 복잡한 프로젝트의 경우 50개에서 100개의 질문에 답해야 하는 경우도 있음

## 📚 핵심 용어
- **하네스 (AI Harness):** 여러 AI 에이전트들을 체계적으로 관리하고 조율하여 복잡한 작업을 수행하는 프레임워크 / 오케스트라 지휘자와 같다. 각각 다른 악기(AI 에이전트)를 연주하는 연주자들을 조율해 하나의 완성된 음악(결과물)을 만든다. / 단일 AI와 하네스의 차이는 - 단일 AI는 혼자 모든 일 처리, 하네스는 전문가팀이 역할분담해서 협업하는 것과 같다.
- **서브 에이전트:** 메인 에이전트가 특정 작업을 위해 생성하고 관리하는 전문화된 보조 AI / 팀장이 프로젝트별로 임시 팀원을 고용하는 것과 같다. 필요할 때 만들어지고, 일이 끝나면 해체된다. / 일반 AI와 서브 에이전트의 차이는 - 일반 AI는 고정된 능력, 서브 에이전트는 특정 업무에 특화된 임시 전문가다.
- **정반합 구조:** 플랜 제안자, 문제점 찾는 검토자, 최종 합의하는 중재자가 협력하는 의사결정 방식 / 법정의 검사-변호사-판사 시스템과 같다. 한쪽은 주장하고, 다른 쪽은 반박하며, 판사가 최종 판단한다. / 일반 검토와 정반합의 차이는 - 일반 검토는 단순 확인, 정반합은 적극적 반박과 토론을 통한 합의 도출이다.
