# 메타 개발자가 육아하면서 부업 4개 돌리는 유일한 방법

## 🧠 이해 (Understand)
- **Summary:** 실리콘밸리 개발자가 Discord 기반 멀티 에이전트 오케스트레이션 시스템(OpenClaw)으로 유튜브·사이드 프로젝트·온라인 강의·썸네일 사업을 동시에 운영하는 워크플로우를 데모 형식으로 공개했다. 핵심은 4개 이상의 AI 서브에이전트가 각 영역을 자율적으로 담당하고, 사용자는 스마트폰 Discord로 방향 지시와 리뷰만 한다는 것이다. CronJob으로 에이전트가 자는 시간에도 강의 제작·코드 배포를 자동 실행하며, Persistent Memory 덕분에 에이전트가 맥락을 누적해 갈수록 더 정확해진다. 코딩은 단 한 줄도 직접 하지 않고, 모든 개발을 Claude Code를 실행하는 에이전트에 위임(delegate)한다. 궁극적으로 본인은 CEO·오케스트레이터 역할만 하며 유튜브→강의→프로젝트→다시 유튜브로 이어지는 복리 효과를 설계 중이다.
- **Core Message:** AI 서브에이전트들에게 실행을 위임하고 자신은 오케스트레이터로만 움직이면, 1인이 다수의 사업·창작·직장 업무를 동시에 스케일업할 수 있다.
> 저는 서비스 만들 때 코딩을 단 한 줄도 쓰고 있지 않습니다. 모든 것을 이 Agent를 통해서 만들고 있어요.
> 핸드폰으로 컴퓨터를 작동할 수 있다는 게 생각보다 엄청난 효율성을 올려줄 수가 있어요.
> 저는 이 모든 프로젝트의 얼굴이 되는 사람이에요. 일종의 CEO가 되는, 1인 기업가가 되는 발판을 만들어두고 있습니다.
❗ 강의 콘텐츠가 1시간마다 AI에 의해 자동 리서치·업데이트·배포되며, 제작자는 하루 1회 피드백만 준다.
❗ YouTube 데일리 리포트(구독자 추이, 조회수, 댓글 분석, 영상 추천)를 매일 아침 AI가 자동 생성해 전송한다.
❗ API 비용 절감을 위해 AI가 직접 브라우저를 열어 Higgsfield 같은 유료 서비스 웹사이트를 사람처럼 조작해 이미지·영상을 생성한다.

## 📚 핵심 용어
- **멀티 에이전트 오케스트레이션:** 여러 AI 에이전트가 각자 맡은 역할을 분담해 협력하도록 조율하는 구조. / 본인은 감독, AI들은 각 포지션 선수. 감독은 전술만 지시하고 실제 플레이는 선수들이 한다. / 단일 챗GPT 대화는 1:1 상담, 멀티 에이전트는 팀 전체를 동시에 지휘하는 것. 병렬 처리 여부가 핵심 차이다.
- **Persistent Memory:** 에이전트가 이전 대화·작업 이력을 누적 기억해 다음 작업에 활용하는 기능. / 오래 함께 일한 비서처럼, 매번 처음부터 설명하지 않아도 내 선호와 프로젝트 맥락을 이미 알고 있다. / 일반 챗봇은 대화창 닫으면 기억 초기화, Persistent Memory는 닫아도 다음 접속 때 이어서 작업 가능.
- **하네스 엔지니어링:** 에이전트가 스스로 결과를 생성·분석·테스트·반복하도록 루프 구조를 설계하는 엔지니어링 방식. / 공장 컨베이어 벨트처럼, 사람이 없어도 부품이 자동으로 조립·검사·포장되는 흐름을 AI로 구현한 것. / 단순 자동화는 정해진 스텝만 반복, 하네스는 결과를 평가해 다음 루프를 스스로 개선한다는 점이 다르다.
- **CronJob 자동화:** 정해진 시간 주기로 특정 작업을 자동 실행하도록 예약하는 스케줄링 방식. / 매일 아침 7시 알람처럼, '1시간마다 강의 업데이트 후 배포'를 한 번 설정하면 자는 동안 알아서 실행된다. / 수동 실행은 사람이 트리거, CronJob은 사람 없이 시간이 트리거. 반복·주기적 작업에 최적화되어 있다.
