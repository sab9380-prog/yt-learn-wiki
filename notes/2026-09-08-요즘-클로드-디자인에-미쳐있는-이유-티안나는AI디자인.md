# 요즘 클로드 디자인에 미쳐있는 이유 \#티안나는AI디자인 \#designsystems \#ClaudeDesign

## 🧠 이해 (Understand)
- **Summary:** 9년 경력 UX 컨설턴트가 클로드 디자인(Claude Artifacts 기반 AI 디자인 툴)을 활용해 피그마 없이 1시간 안에 모바일 UI 7장을 완성하는 실전 워크플로우를 공개한다. 핵심은 '예쁜 화면 만들어줘'가 아니라 PRD 문서, 디자인 시스템 레퍼런스, 스타일 벤치마킹 이미지를 체계적으로 준비해 AI에게 주는 것이다. 기존에 디자이너 1명이 2주·400~600만 원이 들던 작업이 AI 덕분에 기획자·개발자도 직접 할 수 있는 수준으로 단축됐다. AI 시대에 사람이 해야 할 일은 그림 실력이 아니라 문제 진단, 요구사항 정의, 플로우 설계 등 UX 기획 역량이다. 다음 영상에서는 이 결과물을 피그마로 자동 이전 후 클로드 코드로 프론트엔드 바이브 코딩까지 이어갈 예정이다.
- **Core Message:** AI 디자인 시대에 그림 실력보다 중요한 것은 PRD·레퍼런스·플로우를 준비하는 기획 역량이며, 이것만 갖추면 피그마 없이도 1시간 안에 퀄리티 있는 모바일 UI를 만들 수 있다.
> 기교가 아니라 기획인 거죠. 끊김없이 연결되는 사용 경험을 기획하는 것이 사람이 해야 하는 진짜의 일인 겁니다.
> AI는 딸깍하는 도구가 아니라 슈퍼 파워를 가진 신입사원이니까요.
> 단순 작업은 AI로 빠르게 하고 사람은 지식과 정보 사용자 경험에 집중하게 합니다.
❗ 기존에 디자인 시안 프로토타입 제작에 최소 2주, 400~600만 원이 들던 작업이 AI로 1시간 이내에 완성됐다.
❗ 7장의 모바일 UI 화면을 완성하는 동안 피그마를 단 한 번도 열지 않았다.
❗ AI에게 색상을 지정하지 않고 '적절하게'라고만 지시했는데, 기존 디자인 시스템의 색상 체계를 스스로 판단해 올바르게 적용했다.

## 📚 핵심 용어
- **클로드 디자인:** Anthropic의 Claude AI가 디자인 시스템을 인식하고 UI 화면을 생성·수정해 주는 AI 디자인 도구. / 디자인 시스템 규칙집과 내 주문서를 건네면 알아서 화면을 그려주는 디자이너 신입사원 같다. / 피그마는 사람이 직접 그리는 도구, 클로드 디자인은 규칙(디자인 시스템)과 요구사항을 주면 AI가 대신 그려주는 도구다.
- **디자인 시스템:** 색상·폰트·버튼·카드 등 UI 컴포넌트의 규칙과 스타일을 한 곳에 정의해 놓은 설계 표준 문서. / 건물 설계의 자재 규격표처럼, 모든 화면이 같은 버튼·색·간격을 쓰도록 정해 놓은 공통 규칙집이다. / 디자인 시스템은 '공통 규칙'이고, PRD는 '무엇을 만들지 목록'이다. 둘 다 있어야 AI가 일관된 화면을 만든다.
- **PRD 문서:** 서비스의 요구사항·화면 목록·플로우를 정의한 기획 문서로, AI에게 무엇을 만들지 알려주는 지시서. / 건축 도면 없이 집 짓는 인부에게 구두로만 설명하는 것과 달리, 도면처럼 상세한 주문서를 건네는 것이다. / PRD는 '무엇을 만들 것인가'를 정의하고, 디자인 시스템은 '어떤 스타일로 만들 것인가'를 정의한다.
- **뉴모피즘:** 밝은 배경에 부드러운 그림자를 써서 UI 요소가 화면에서 솟아오르거나 눌린 듯 보이게 하는 디자인 스타일. / 실리콘 버튼처럼 화면 속 요소가 약간 볼록하게 튀어나온 느낌을 주는 인테리어 스타일이다. / 플랫 디자인은 그림자 없이 색으로만 구분하지만, 뉴모피즘은 미세한 명암 그림자로 입체감을 준다.

  - 담당: 나
  - 이유: PRD 없이 AI에게 디자인을 시키면 일관성 없는 결과가 나온다. 이것이 AI 디자인 품질을 결정하는 핵심 입력값이다.
- [ ] 피그마 커뮤니티에서 iOS/Android UI 키트를 다운로드하고, 핀터레스트에서 원하는 스타일 레퍼런스 이미지 5~10장을 수집한 뒤, 클로드 디자인에서 디자인 시스템 생성 및 커스터마이징을 실습한다. — ⏰ 2주 내 · ⚡ 2~4시간
  - 담당: 나
  - 이유: 레퍼런스 품질이 AI 출력 품질을 직접 결정하므로, 실습으로 레퍼런스 수집 → 커스터마이징 → 화면 생성 흐름을 한 번 체험해야 한다.
- 자료: 피그마 커뮤니티 UI 키트 검색: https://www.figma.com/community (iOS/Android UI Kit)
- 자료: 핀터레스트 디자인 레퍼런스 검색: neumorphism UI, glassmorphism UI
- 자료: 클로드 디자인(Claude Artifacts 디자인 기능): https://claude.ai — 확인 필요 (영상에서 'Claude Design'으로 지칭하나 공식 제품명 별도 확인 필요)
- 자료: 피그마 MCP 연결 방법: 'Figma MCP 연결' 키워드로 검색 (영상에서 인터넷 참고 권장)
- Timeline: 1주 차: PRD 문서 작성 + 레퍼런스 이미지 수집 → 2주 차: 클로드 디자인 실습(디자인 시스템 생성·커스터마이징·화면 생성) → 3주 차: 다음 영상 공개 후 피그마 자동 이전 및 바이브 코딩 단계 진행
