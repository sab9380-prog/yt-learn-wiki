# \[RISK\] AI 에이전트 프레임워크를 잘못 고르면 2026년 프로젝트는 실패한다 | \#NEWIT

## 🧠 이해 (Understand)
- **Summary:** 2026년 AI 에이전트 프레임워크의 현실적인 평가와 실무 선택 가이드를 제시하는 영상입니다. 화려한 데모에 속지 말고 실제 프로덕션 환경에서 통용되는 기준으로 프레임워크를 평가해야 한다고 강조합니다. 제어 가능성, 가시성, 상태 관리라는 3대 핵심 기준을 바탕으로 LangGraph(S-Tier), OpenAI Agents SDK(A-Tier), CrewAI·AutoGen(B-Tier) 순으로 평가합니다. 특히 LangGraph는 체크포인팅과 상태 관리로 엔터프라이즈급 안정성을 제공하지만 학습 곡선이 가파르고, CrewAI는 초기 개발은 빠르지만 운영 단계에서 '추상화의 저주'에 빠진다고 분석합니다. 무한 루프, API 비용 폭증, 보안 취약점 등 실무에서 마주치는 함정들을 구체적으로 설명하며, 프레임워크 선택은 기능보다 비즈니스 제어권 보장을 우선해야 한다고 결론짓습니다.
- **Core Message:** 화려한 AI 에이전트 데모에 속지 말고, 실제 프로덕션 환경에서 제어·가시성·상태 관리가 보장되는 프레임워크를 비즈니스 제어권 기준으로 선택해야 한다.
> 화려한 AI 에이전트 데모에 속지 마십시오. 실무 현장에서 마주하는 에이전트 프로젝트의 현실은 참혹합니다.
> 우리는 단순히 작동하는 코드가 아니라, 예측 가능한 시스템을 설계해야 합니다.
> 도구가 여러분을 지배하게 두지 마십시오.
❗ 실제 배포 단계에서 90% 이상의 에이전트 프로젝트가 중단되는 이유는 '제어 불가능성' 때문이다
❗ 단 10분 만에 한 달 치 예산인 수백 달러가 무한 루프로 증발하는 건 현장에서 결코 드문 일이 아니다
❗ 2026년 기준으로 엔터프라이즈 환경에서 생존하기 위한 에이전트의 3대 핵심 기준은 제어 가능성, 가시성, 상태 관리다

## 📚 핵심 용어
- **체크포인팅:** 에이전트가 각 작업 단계마다 상태를 데이터베이스에 저장하는 기능 / 게임의 세이브 포인트와 같다. 중간에 실패해도 처음부터 다시 시작할 필요 없이 저장된 지점부터 재개할 수 있다. / 단순 재시도는 처음부터 다시 시작하지만, 체크포인팅은 중단된 지점부터 재개해 토큰 비용을 절약한다.
- **Human-in-the-loop:** AI 에이전트가 고위험 작업 시 인간의 승인을 받아 실행하는 방식 / 은행 대출처럼 중요한 결정은 기계가 아닌 담당자의 최종 승인을 거쳐야 하는 것과 같다. / 완전 자동화는 AI가 모든 결정을 내리지만, Human-in-the-loop는 중요한 지점에서 인간이 개입할 수 있다.
- **추상화의 저주:** 고수준 추상화로 인해 내부 동작을 파악하기 어려워지는 현상 / 자동차 보닛을 열 수 없는 것과 같다. 겉보기엔 편리하지만 고장 났을 때 어디가 문제인지 찾을 수 없다. / 저수준 코딩은 복잡하지만 디버깅이 쉽고, 고수준 추상화는 편리하지만 문제 발생 시 원인 파악이 어렵다.
- **오케스트레이션:** 여러 에이전트나 서비스들의 실행 순서와 협업을 체계적으로 관리하는 방식 / 오케스트라 지휘자가 각 악기의 연주 타이밍을 조율하듯, 에이전트들의 실행 흐름을 제어한다. / 단순 API 호출은 일회성 요청이지만, 오케스트레이션은 복잡한 워크플로우 전체를 체계적으로 관리한다.
