# 크롤링 우회 (Anti-Bot) 종합

## 핵심: 세 노트가 공통으로 말하는 것

**"공개 데이터를 가져오는 건 합법이지만, 사이트는 점점 더 정교하게 막는다."**

2024년 미국 연방법원 판결로 공개 데이터 수집의 합법성은 확립됐다 [[2026-05-22-IP-차단-캡챠도-다-뚫어버린다-이걸로-크롤링-AI-에이전트-코딩]]. 그러나 최신 봇 탐지는 IP만이 아니라 마우스 움직임·캔버스 렌더링·TLS 지문까지 분석하기 때문에 [[2026-05-22-IP-차단-캡챠도-다-뚫어버린다-이걸로-크롤링-AI-에이전트-코딩]], 단순 코드로는 막힌다.

---

## 서로 다른 접근법: 무료 vs 유료

| 접근 | 도구 | 강점 | 한계 |
|---|---|---|---|
| **무료 오픈소스** | 인세인 서치 (클로드 코드 플러그인) | 추가 비용 없음, 내부 API 자동 탐색 → Playwright 순서로 단계적 시도 | 클로드 코드 구독 전제 [[2026-06-25-시즌-3-온갖-크롤링-코드-안녕-공개된-페이지를-모두-긁어버리는]] |
| **유료 서비스** | 브라이트 데이터 | 7,200만 개 실제 가정집 IP, 캡차 자동 해결, TLS 지문 조작 원스톱 제공 | 비용 발생 [[2026-05-22-IP-차단-캡챠도-다-뚫어버린다-이걸로-크롤링-AI-에이전트-코딩]] |

---

## 핵심 우회 기술 3가지

1. **레지던셜 프록시** — 데이터센터 IP 대신 실제 가정집 IP로 접속, 봇으로 의심받지 않음 [[2026-05-22-IP-차단-캡챠도-다-뚫어버린다-이걸로-크롤링-AI-에이전트-코딩]]
2. **내부 API 호출** — 페이지 HTML을 긁는 대신, 사이트가 내부적으로 쓰는 데이터 통로를 직접 요청 [[2026-06-25-시즌-3-온갖-크롤링-코드-안녕-공개된-페이지를-모두-긁어버리는]]
3. **Playwright (실제 브라우저 자동화)** — 위 두 방법이 막혔을 때 최후 수단. 느리지만 봇 탐지 우회율 가장 높음 [[2026-06-25-시즌-3-온갖-크롤링-코드-안녕-공개된-페이지를-모두-긁어버리는]]

---

## 주의: 크롤링하는 쪽도, 당하는 쪽도 보안을 챙겨야

크롤링을 *하는* 입장에서는 우회 기술이 필요하지만, 내 서비스가 *당하는* 입장이라면 Rate Limit을 **반드시 백엔드에** 설정해야 한다. 프론트엔드 제한은 개발자 도구로 쉽게 우회된다 [[2026-05-22-바이브코딩-보안-실수-3가지]]. AI로 앱을 만들 때 Rate Limit이 빠지는 경우가 많으므로 의도적으로 확인해야 한다 [[2026-05-22-바이브코딩-보안-실수-3가지]].

---

## 한 줄 정의

> 크롤링 우회란, 공개 데이터를 합법적으로 가져오기 위해 봇 탐지(IP·캡차·TLS 지문)를 단계적으로 돌파하는 기술이며, 동시에 내 서비스도 같은 방법으로 공격받을 수 있다는 사실을 기억해야 한다.
