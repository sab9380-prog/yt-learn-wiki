# 왕초보도 당장 따라할 수 있는 클로드 디자인 15분 속성 마스터 클래스ㅣ이 영상만 보면 원하는 것을 마음대로 만들 수 있습니다.

## 🧠 이해 (Understand)
- **Summary:** 이 영상은 Claude(클로드) AI의 디자인 기능을 15분 만에 마스터하는 방법을 소개한다. 공식 문서에서 강조하는 5가지 핵심 팁을 중심으로 설명하며, 실습으로 매출 대시보드를 직접 제작한다. 첫째, 효과적인 프롬프트 작성을 위해 '무엇을·어떻게 배치·어떤 정보·누가 사용'의 4가지를 명시해야 한다. 둘째, 구글/핀터레스트 레퍼런스 이미지나 getdizen.md 코드 등 맥락 자료를 풍부하게 제공해야 한다. 셋째, 에딧 기능·코멘트·마크업으로 수정이 자유롭고 Ctrl+Z도 지원된다. 넷째, 작게 시작해서 수정을 통해 점진적으로 완성해 나가야 한다. 다섯째, 클로드 디자인을 실제 디자이너처럼 대하며 전문 용어와 다양한 레이아웃 요청이 가능하다. 완성된 디자인은 Claude Code로 넘겨 실제 데이터 연동·서버·배포 작업을 이어 진행할 수 있다.
- **Core Message:** 클로드 디자인에서 4요소 프롬프트 + 레퍼런스 맥락 제공 + 수정 기능을 익히면, 비디자이너도 실제 서비스 수준의 UI를 만들고 Claude Code로 배포까지 연결할 수 있다.
> AI는 주격제한이 없는 굉장히 자유로운 영혼이고, 이 영혼을 되게 좁히고 좁혀서 어떤 특정 초점을 맞춰 나가는 거, 내가 원하는 바에 맞게 깎고 깎아서 딱 하나만 남기는 것이 굉장히 중요하다.
> 수정을 하나도 하지 않았고, 이런 것들도 클로드 디자인에서 다 만들 수가 있습니다.
> AI로 무언가를 만든다는 것에 대한 진입 장벽이 되게 낮아졌거든요.
❗ 클로드 디자인에서 Ctrl+Z(실행 취소)가 지원되어, 잘못 수정한 내용을 즉시 되돌릴 수 있다.
❗ getdizen.md에서 애플 등 대기업의 디자인 시스템 코드를 복사해 클로드 디자인에 붙여넣는 것만으로 해당 브랜드 스타일이 즉시 반영된다.
❗ 클로드 디자인이 작업 전 사용자에게 설문 형태로 세부 조건(통화 단위, 언어 등)을 직접 물어보는 인터랙티브 플래닝 기능이 있다.

## 📚 핵심 용어
- **클로드 디자인 (Claude Design):** Anthropic의 Claude AI가 프롬프트만으로 웹/앱 UI를 HTML 코드와 함께 즉시 생성해 주는 프로토타이핑 도구. / 인테리어 디자이너에게 '이 사진처럼 만들어 줘'라고 말하면 도면과 3D 시안을 바로 뽑아 주는 것과 같다. / 피그마·캔바는 사람이 직접 배치해야 하지만, 클로드 디자인은 말로 요청하면 AI가 코드까지 짜준다는 점이 다르다.
- **바이브 코딩 (Vibe Coding):** 코딩 지식 없이 자연어 대화만으로 AI에게 소프트웨어를 제작시키는 개발 방식. / 요리법 몰라도 셰프에게 '매운 파스타 해줘'라고 말하면 요리가 나오는 것처럼, 코드 없이 결과물을 얻는다. / 전통 코딩은 개발자가 직접 코드를 작성하지만, 바이브 코딩은 의도와 방향만 제시하고 AI가 코드를 생성한다.
- **클로드 코드 (Claude Code):** 클로드 디자인에서 만든 UI 껍데기에 실제 데이터·서버·배포 로직을 연결하는 AI 기반 코딩 환경. / 클로드 디자인이 건물 외관을 세웠다면, 클로드 코드는 전기·수도·인테리어 내부 공사를 마무리하는 단계다. / 클로드 디자인은 시각적 껍데기(프런트엔드 프로토타입)를 만들고, 클로드 코드는 실제 작동하는 서비스로 완성한다.
- **getdizen.md:** 애플·구글 등 대기업의 디자인 시스템(색상·폰트·버튼 등)을 코드 스니펫으로 정리한 참고 웹사이트. / 유명 셰프의 레시피 북처럼, 검증된 브랜드 디자인 규칙을 복사해서 내 작업에 바로 붙여넣을 수 있다. / 핀터레스트/구글 이미지가 시각적 영감을 주는 반면, getdizen.md는 실제 적용 가능한 코드 형태의 디자인 규칙을 제공한다.
