# 클로드 코드 안에서 코덱스를 사용하는 코덱스 플러그인 세팅 가이드

## 🧠 이해 (Understand)
- **Summary:** 클로드 코드에서 오픈AI 코덱스를 플러그인으로 함께 사용할 수 있게 된 새로운 기능을 소개하는 영상입니다. 코덱스 플러그인을 깃허브에서 설치하는 과정부터 실제 사용법까지 단계별로 시연합니다. 주요 명령어는 /codex-review(코드 검토), /codex-adversarial-review(까다로운 검토), /codex-rescue(코덱스에 직접 작업 위임), /codex-status(진행 상황 확인) 등입니다. 실제 테스트에서는 에어비앤비 스타일의 가족 앨범 앱을 만들고 코덱스로 리뷰하는 과정을 보여줍니다. 코덱스에 처음부터 작업을 맡기는 것은 속도가 매우 느리므로, 클로드 코드로 작업한 후 코덱스로 리뷰받는 방식을 추천합니다.
- **Core Message:** 클로드 코드와 코덱스를 한 화면에서 함께 사용하되, 클로드 코드로 작업하고 코덱스로 리뷰받는 방식이 가장 효율적이다.
> 플러그인이라는 거는 에이전트 MD 스킬과 MCP 그리고 서브에이전트 훅스를 이제 합쳐 놓은 걸 우리가 플러그인이라고 한다
> 코덱스 레스큐는 처음부터 작업시키기는 그렇게 좋지는 않다. 좋지 않다 수준이 아니라 이건 작업이 그냥 거의 안 되는 수준이에요
> 클로드 코드한테 작업을 시키고, 코덱스한테 리뷰 작업 시키고, 리뷰가 되고 나면 거꾸로 다시 우리 클로드 코드한테 다시 작업을 시키면 되겠죠
❗ 코덱스 플러그인의 /codex-rescue 명령으로 직접 작업을 시키면 10분 이상 기다려도 제대로 진행되지 않을 정도로 속도가 느리다
❗ 깃허브의 스타(투표) 시스템으로 플러그인의 품질을 판단할 수 있으며, 포크(복사) 수도 인기도를 보여주는 지표다
❗ 플러그인은 사용자가 직접 만들 필요 없이 개발자들이 여러 기능을 묶어서 배포한 것을 가져다 쓰는 방식이다

## 📚 핵심 용어
- **서브에이전트:** 메인 AI가 작업하는 동안 백그라운드에서 보조 업무를 담당하는 별도 AI 프로세스 / 요리사(메인)가 요리하는 동안 뒤에서 설거지하는 보조(서브)처럼, 주 작업과 별개로 돌아가는 보조 AI다. / 일반 AI는 한 번에 하나씩 순차 작업하지만, 서브에이전트는 동시에 여러 작업을 병렬 처리할 수 있다.
- **MCP:** 서로 다른 AI 시스템들이 데이터와 기능을 공유할 수 있게 연결해주는 통신 규약 / 서로 다른 언어를 쓰는 사람들 사이의 통역사처럼, 다른 AI끼리 소통할 수 있게 해주는 번역기다. / API는 단순 데이터 전송이지만, MCP는 AI의 능력과 컨텍스트까지 함께 공유하는 더 깊은 연결이다.
- **훅스:** 특정 상황이나 이벤트가 발생했을 때 자동으로 다른 기능을 실행시키는 트리거 시스템 / 문 열리면 자동으로 켜지는 현관등처럼, 어떤 조건이 만족되면 미리 정해둔 작업이 자동 실행된다. / 슬래시 명령은 사용자가 직접 실행하는 것이고, 훅스는 조건 만족 시 자동으로 실행되는 차이가 있다.
- **플러그인:** 에이전트, 스킬, MCP, 서브에이전트, 훅스 등을 묶어서 쉽게 설치할 수 있게 패키지화한 확장 기능 / 컴퓨터에 프로그램 설치하듯이, 복잡한 설정을 한번에 끝내고 바로 쓸 수 있게 만든 기능 꾸러미다. / 개별 기능들은 하나씩 따로 설정해야 하지만, 플러그인은 여러 기능을 한번에 설치하고 바로 사용 가능하다.
