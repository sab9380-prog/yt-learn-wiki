# 진짜는 에이전트가 아니라 '스킬'이었다

## 🧠 이해 (Understand)
- **Summary:** 앤스로픽은 사내 데이터 분석의 95%를 AI(Claude)로 자동화하는 데 성공했으며, 그 핵심은 4층 구조 시스템이다. 1층은 표준 데이터셋(단일 진실의 원천), 2층은 신뢰도 순서로 쌓인 참고 자료, 3층은 AI에게 '일하는 방법'을 알려주는 스킬 문서, 4층은 다층 검증 체계다. 특히 스킬 문서 하나를 추가했더니 정확도가 21%에서 95%로 뛰었으며, 반대로 스킬 문서가 낡으면 한 달 만에 65%로 추락했다. 과거 SQL 수천 개를 날것으로 줘도 정확도가 1%도 안 오른 실험은 '정보의 양보다 구조화된 맥락'이 핵심임을 증명한다.
- **Core Message:** AI 정확도는 모델 성능이 아니라 구조화된 맥락(스킬 문서)과 강제된 유지관리가 결정한다.
> 낡은 문서는 모델 한 개보다 AI 성능을 더 빨리 죽인다.
> 문제는 정보 접근이 아니었어요. 정보는 이미 있었습니다. 진짜 문제는 구조였어요.
> 에이전트를 만드는 것이 아닙니다. 스킬을 만드는 거예요.
❗ 과거 SQL 수천 개 중 80%가 관련 있었음에도, 날것으로 AI에게 주었을 때 정확도가 1%도 오르지 않았다.
❗ 스킬 문서 추가 하나로 정확도가 21%에서 95%로 상승했으나, 방치 시 한 달 만에 65%로 추락했다.
❗ 적대적 검토를 적용하면 정확도 +6%, 토큰 비용 -32%이지만 응답 시간이 72% 늘어난다.

## 📚 핵심 용어
- **스킬(Skill):** AI가 데이터 분석을 수행할 때 따라야 할 절차·판단 기준·참고 순서를 담은 업무 매뉴얼. / 신입에게 주는 선배의 업무 매뉴얼. 데이터만 던져줄 때와 일하는 법까지 알려줄 때의 차이다. / 프롬프트는 그때그때 던지는 지시문, 스킬은 재사용 가능한 표준 업무 절차서. 스킬은 쌓일수록 자산이 된다.
- **표준 데이터셋(Single Source of Truth):** 회사 내 특정 지표를 계산할 때 반드시 참조해야 할 단 하나로 지정된 공식 데이터. / 음식점 표준 레시피. 알바가 바뀌어도 김치찌개 맛이 같으려면 레시피가 하나여야 한다. / 일반 데이터셋은 여러 시트에 각자 다른 방식으로 존재, 표준 데이터셋은 '이것만 써라'고 못 박은 유일본.
- **시맨틱 레이어(Semantic Layer):** 회사가 공식 인증한 지표 계산 규칙을 시스템 수준에서 보장해주는 의미 정의 계층. / 도량형 표준청 같은 존재. '1킬로그램'의 정의를 나라가 공식 보장하듯, 지표 정의를 시스템이 보장한다. / 대시보드는 계산 결과만 보여주지만, 시맨틱 레이어는 그 계산 방법 자체를 표준으로 잠근다.
- **적대적 검토(Adversarial Review):** AI가 생성한 답변을 다른 AI 검토자가 의심하며 재검증하는 자기비판적 품질 확인 과정. / 본인이 쓴 보고서를 동료가 빨간펜으로 다시 검토하는 것. 한 사람 눈보다 두 사람 눈이 낫다. / 일반 AI 응답은 한 번 생성으로 끝, 적대적 검토는 정확도+6% 대신 응답속도-72%의 트레이드오프가 따른다.
