# 클로드 코드로 어떤 유튜브 채널이든 복사하는 방법 (코딩 필요 없음)

## 🧠 이해 (Understand)
- **Summary:** 해외 인기 유튜브 채널을 체계적으로 분석하고 벤치마킹하는 방법을 소개하는 영상입니다. 클로드 코드(Claude for VS Code)를 활용해 성공 채널의 대본 스타일, 영상 구성, 썸네일 디자인을 자동으로 분석하고, 이를 바탕으로 새로운 콘텐츠 아이디어, 대본, 이미지 프롬프트를 생성하는 과정을 단계별로 설명합니다. 코딩 지식 없이도 마크다운 파일에 프롬프트를 설정하면 클로드가 채널 분석부터 콘텐츠 제작까지 자동화해줍니다. 실제로 해외 고양이 심리학 채널을 벤치마킹하여 대본과 썸네일을 생성하는 전 과정을 시연하며, 구글 플로우와 자동화 도구까지 활용한 완전한 워크플로우를 제시합니다.
- **Core Message:** 클로드 코드와 체계적인 프롬프트 설계로 성공 채널의 공식을 분석하고 나만의 콘텐츠로 재창조할 수 있다.
> 그 비슷하게가 제일 어렵습니다
> 벤치마킹 채널의 대본을 그대로 베끼는게 아닙니다. 그 채널의 성공 요인만 분석해서 저희만의 독창적인 대본에 적용하는 방식입니다
> MD 파일은 클로드에게 주는 고정 지시서라고 보시면 됩니다
❗ 구글 플로우는 프로 기능을 사용해도 이미지 생성이 무료
❗ 클로드 코드에서 이미지 업로드 시 Shift 키를 눌러야 정상 작동
❗ 배우 오토메이션으로 여러 이미지 프롬프트를 한 번에 자동 생성 가능

## 📚 핵심 용어
- **클로드 코드:** VS Code에서 클로드 AI를 사용할 수 있게 해주는 확장 프로그램 / 개인 비서가 내 컴퓨터에 상주하며 파일을 보고 즉시 분석·작업해주는 것과 같다. / 일반 클로드 웹은 채팅만 가능하지만, 클로드 코드는 파일을 직접 읽고 편집할 수 있다.
- **마크다운 파일:** 클로드 코드가 세션 시작 시 자동으로 읽는 .md 확장자 파일 / 비서에게 주는 업무 매뉴얼 같은 것. 한 번 써두면 매번 지시하지 않아도 알아서 따른다. / 일반 프롬프트는 매번 입력해야 하지만, 마크다운은 한 번 설정하면 자동으로 기억한다.
- **채널 벤치마킹:** 성공한 채널의 콘텐츠 구조와 스타일을 분석해 자신의 채널에 적용하는 것 / 맛있는 요리의 레시피를 연구해서 내 스타일로 새 요리를 만드는 것과 같다. / 단순 모방은 그대로 따라하는 것이지만, 벤치마킹은 성공 요인만 추출해 독창적으로 적용한다.
- **프롬프트 자동화:** 미리 설정한 명령어 체계로 AI가 순차적으로 작업을 수행하도록 하는 방식 / 공장의 컨베이어 벨트처럼, 한 번 설계해두면 원료(채널링크)만 넣으면 완성품(콘텐츠)이 나온다. / 수동 프롬프트는 매번 명령해야 하지만, 자동화는 한 번 설계로 반복 작업이 가능하다.
