## 🧠 이해 (Understand)
- **Summary:** 웹 크롤링과 데이터 수집 시 직면하는 기술적 차단(IP 차단, 캡차, TLS 지문 등)을 우회할 수 있는 브라이트 데이터(Bright Data) 서비스를 소개한다. 크림과 같은 차단이 까다로운 사이트들도 브라이트 데이터의 레지던셜 프록시와 스크래핑 브라우저 API를 통해 성공적으로 크롤링할 수 있음을 실제 코드와 함께 시연한다. 2024년 미국 연방법원 판결로 공개 데이터 수집의 합법성이 확립되었으며, 브라이트 데이터는 전 세계 7,200만 개 이상의 실제 가정집 IP를 윤리적 SDK 모델로 확보하여 서비스를 제공한다. 캡차 자동 해결, 국가별 IP 접속, TLS 지문 조작 등의 기능을 원스톱으로 제공하여 개발자가 차단 우회보다 서비스 개발에 집중할 수 있도록 돕는다.
- **Core Message:** 웹 크롤링 시 기술적 차단을 우회하는 시간을 줄이고, 브라이트 데이터 같은 전문 서비스를 활용해 실제 서비스 개발에 집중하라
> 이거 솔직히 코딩이 아니라 거의 마법 수준이죠
> 더 이상 차단 뚫느라 밤새지 마시고 그 시간에 더 좋은 서비스를 만드는데 집중하시길 바래요
> 로그인하지 않아도 볼 수 있는 공개된 데이터는 누구의 소유도 아니고 누구나 접근하는 권리가 있다
❗ 브라이트 데이터는 전 세계 195개국에 7,200만 개 이상의 실제 가정집 IP를 보유하고 있다
❗ 2024년 미국 연방법원에서 브라이트 데이터가 메타와 트위터를 상대로 한 소송에서 승소하여 공개 데이터 수집의 합법성이 확립되었다
❗ 최신 보안 솔루션들은 IP뿐만 아니라 마우스 움직임, 캔버스 렌더링 방식까지 분석해 봇을 탐지한다

## 📚 핵심 용어
- **레지던셜 프록시:** 실제 가정집 IP 주소를 통해 인터넷에 접속하는 프록시 서비스 / 회사 컴퓨터 대신 집 컴퓨터로 인터넷을 하는 것과 같다. 서버 IP는 의심받지만 집 IP는 일반 사용자로 보인다. / 데이터센터 프록시는 서버 IP라 차단당하기 쉽고, 레지던셜 프록시는 실제 가정집 IP라 차단이 어렵다.
- **TLS 지문:** 브라우저나 기기의 고유한 암호화 통신 특성으로 봇을 판별하는 기술 / 온라인 쇼핑몰에서 결제할 때 카드 서명을 확인하는 것처럼, 웹사이트가 접속자의 '디지털 서명'을 체크하는 방식이다. / IP 주소는 위치만 보지만, TLS 지문은 브라우저의 세부 특성까지 분석해 더 정교하게 봇을 탐지한다.
- **캐이터 자동 해결:** 신호등 찾기 같은 로봇 방지 퀴즈를 AI가 자동으로 푸는 기능 / 학원에서 숙제를 대신 풀어주는 과외 선생님과 같다. 어려운 퀴즈가 나와도 알아서 풀어준다. / 수동 해결은 사람이 직접 클릭해야 하고, 자동 해결은 AI가 백그라운드에서 알아서 처리한다.
- **윤리적 SDK 모델:** 사용자가 동의한 조건 하에서만 유휴 네트워크 자원을 빌려쓰는 방식 / 카풀과 같은 개념이다. 내가 차를 안 쓸 때 다른 사람에게 빌려주고, 대신 광고 없는 앱을 쓰는 거래다. / 해킹은 무단으로 자원을 탈취하지만, 윤리적 모델은 사용자 동의와 혜택 제공을 전제로 한다.
