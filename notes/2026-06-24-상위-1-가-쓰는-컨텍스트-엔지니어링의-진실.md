# 프롬프트 엔지니어링은 끝났다｜상위 1%가 쓰는 컨텍스트 엔지니어링의 진실

[[_category-일반학습]]

## 🧠 이해 (Understand)
- **Summary:** 프롬프트 엔지니어링의 시대는 사실상 끝났으며, OpenAI 공식 문서도 모델 업데이트마다 기존 프롬프트 기법 사용을 경고한다. 프린스턴 대학 연구에서 최신 추론 모델에 과거 기법을 적용하니 성능이 36포인트 하락했고, 와튼스쿨 리포트도 시간만 80% 더 소모되고 성능은 오히려 저하된다고 밝혔다. LLM은 확률 기반 단어 예측 기계이므로 ①지식 고정 ②비공개 정보 접근 불가 ③환각 현상이라는 세 가지 치명적 결함을 가진다. 이를 극복하는 진짜 핵심은 '컨텍스트 엔지니어링'으로, 단순히 어떻게 질문하느냐가 아니라 AI가 제대로 작동할 수 있도록 정확한 자료·도구·메모리를 시스템적으로 설계하는 개념이다. 반대로 정보를 무작정 많이 넣으면 컨텍스트 오염·분산·혼란이라는 부작용이 생기며, 버클리 대학 연구에서 불필요한 도구가 37개 주어졌을 때 성능이 눈에 띄게 저하됐다. 올바른 접근은 ①복잡한 문제를 단계별로 잘게 쪼개고 ②외부 저장소를 활용한 컨텍스트 오프로딩 ③RAG 기반 컨텍스트 선택 ④컨텍스트 압축 ⑤에이전트 분리를 통한 컨텍스트 격리를 통해 재사용 가능한 워크플로우 파이프라인을 구축하는 것이다. 이 구조는 새 모델이 나와도 흔들리지 않으므로, 매번 새 프롬프트 가이드를 외울 필요가 없다.
- **Core Message:** 프롬프트 한 줄을 다듬는 시대는 끝났고, 이제는 AI가 제대로 작동할 수 있도록 데이터·도구·흐름을 시스템으로 설계하는 '컨텍스트 엔지니어링'이 진짜 경쟁력이다.
> 진짜 산업용 거대 언어 모델을 만드는 건 프롬프트가 아니라 컨텍스트 엔지니어링이다 — 안드레이 카르파시 (테슬라 전 AI 디렉터)
> 여러분을 대체하는 건 AI 자체가 아니라 이런 AI의 워크플로우를 자유자재로 설계할 줄 아는 다른 누군가가 될 거예요.
> 쓰레기 같은 데이터를 무작정 들이붓는 건 정답이 아니다.
❗ 프린스턴 대학 연구에서 최신 추론 모델에 과거 프롬프트 기법(Chain-of-Thought 등)을 적용했더니 성능이 36포인트 하락했다.
❗ 버클리 대학 연구에서 AI에게 함수(도구)를 37개 제공했을 때 꼭 필요한 도구 몇 개만 줬을 때보다 성능이 눈에 띄게 저하됐다.
❗ OpenAI는 새 모델이 출시될 때마다 프롬프팅 가이드를 아예 새로 작성하며, 이전 모델에서 필수였던 'Chain-of-Thought(차근차근 생각해봐)' 기법을 최신 o1 모델 가이드에서 명시적으로 사용하지 말라고 경고하고 있다.

## 📚 핵심 용어
- **컨텍스트 엔지니어링:** AI가 정확히 작동하도록 필요한 데이터·도구·메모리를 시스템적으로 설계하는 기술. / 요리사에게 '맛있게 요리해'라고 말하는 대신, 신선한 재료·레시피·조리도구를 미리 정확히 세팅해 주는 것과 같다. / 프롬프트 엔지니어링은 질문 문장을 다듬는 것, 컨텍스트 엔지니어링은 AI가 일할 작업 환경 전체를 설계하는 것.
- **환각(Hallucination):** AI가 모르는 것을 모른다 하지 않고 그럴듯한 거짓 답변을 생성하는 현상. / 자신감 넘치는 신입사원이 모르는 내용을 솔직히 말하는 대신 그럴듯하게 지어내어 보고하는 것과 같다. / 단순 오류는 정답이 없어 틀리는 것, 환각은 틀린 답을 맞다고 확신하며 생성하는 것이라 더 위험하다.
- **RAG (검색증강생성):** AI가 답변할 때 외부 데이터베이스에서 관련 정보를 검색해 근거로 활용하는 방식. / 오픈북 시험처럼, 모든 걸 외우지 않아도 필요할 때 책(외부 자료)을 펴서 정확한 답을 찾는다. / Fine-tuning은 AI 자체를 재훈련해 지식을 내재화하는 것, RAG는 외부 자료를 실시간 참조하는 것으로 자료 갱신이 훨씬 쉽다.
- **컨텍스트 오염:** AI에게 정보를 과도하게 주입했을 때 AI가 자신의 오류나 거짓을 사실로 믿어버리는 현상. / 책상에 서류가 너무 많으면 틀린 메모를 진짜 결재 문서로 착각해 처리해버리는 것과 같다. / 컨텍스트 분산은 불필요한 과거 기록에 얽매여 새 판단을 못 내리는 것, 오염은 오류 자체를 사실로 수용하는 것으로 더 근본적인 문제다.
