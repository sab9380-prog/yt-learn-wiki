# 클로드 스킬 (Claude Skill)

## 핵심 정의 — 노트들이 공통으로 말하는 것

**클로드 스킬 = AI에게 내 일하는 방식을 가르쳐둔 재사용 가능한 작업 매뉴얼**

매번 프롬프트를 새로 쓰는 대신, 반복 업무의 규칙·절차·기준을 한 번 저장해두면 버튼 하나로 재실행되는 구조다. [[2026-06-24-클로드-코드-10분안에-레벨업-시키는-필수-스킬-7개-전부-공개합니다]] [[2026-06-25-클로드-AI-업무-자동화-3단계]] [[2026-06-30-MD-완벽-개념-설명-claude-claudeskills]]

## 상충 · 주의점

**⚠️ 스킬이 많을수록 좋지 않다**
스킬이 늘수록 Claude의 컨텍스트(단기 기억 용량)를 잡아먹어 오히려 작업 품질이 낮아진다. 300일 사용자가 수십 개 설치 후 실제로 살아남은 건 단 8개. [[2026-06-24-클로드-코드-10분안에-레벨업-시키는-필수-스킬-7개-전부-공개합니다]]

**⚠️ 스킬(문서)이 낡으면 AI가 망가진다**
스킬 문서를 방치하면 한 달 만에 정확도 95% → 65%로 급락. 스킬은 만드는 것보다 **최신 상태 유지**가 더 중요하다. [[2026-06-25-진짜는-에이전트가-아니라-스킬-이었다]] [[2026-06-08-진짜는-에이전트가-아니라-스킬-이었다]]

**⚠️ GitHub 별(star) 수 = 품질 아님**
일부 저장소는 설치 스크립트에 자동 별 누르기 코드를 숨겨둔다. [[2026-06-30-MD-완벽-개념-설명-claude-claudeskills]]

## 실행 순서 (비개발자용 최소 진입)

1. **지금 가장 반복하는 업무 1개** 고른다
2. Claude와 함께 그 업무를 행동 단위로 잘게 쪼갠다
3. 그 흐름을 스킬 하나로 저장한다
4. 맞는 기성 스킬이 없으면 **스킬 크리에이터**로 직접 만든다
