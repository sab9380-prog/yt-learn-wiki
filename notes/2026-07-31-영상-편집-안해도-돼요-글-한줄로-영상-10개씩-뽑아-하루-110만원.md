# "영상 편집 안해도 돼요" 글 한줄로 영상 10개씩 뽑아 하루 110만원 버는 여자 (뻔한 AI 프로그램❌)

## 🧠 이해 (Understand)
- **Summary:** AI 도구를 활용해 얼굴 노출 없이 지식·다큐 콘텐츠를 자동 생성하는 유튜버 '다람'의 운영 방식을 공개한 영상이다. 클로드 코드(VS Code)로 논문 기반 대본을 자동 작성하고, '튜브워커'라는 프로그램으로 TTS·이미지·스토리보드를 일괄 생성한다. 캡컷 프로젝트 파일로 내보내 자체 제작 '탭 효과 자동' 툴로 줌인·전환 효과를 무작위 삽입하면 영상이 완성된다. 이 워크플로우로 4개월 만에 수익 창출 채널 4개를 운영하며 월 1,400만 원을 달성했다. 영상 후반부는 해당 강사(개발남 노시)의 강의 및 무료 특강 홍보로 이어진다.
- **Core Message:** 클로드 코드·튜브워커 등 AI 도구를 파이프라인으로 연결하면 얼굴·촬영 없이도 고RPM 지식 채널로 월 1,000만 원대 수익이 가능하다.
> 영상 퀄리티가 공중파 다큐 수준이네요 — 시청자 댓글
> 저도 이제 뭘 더 할 수 있을까 생각했을 때 유튜브라는 길이 있는지 전혀 몰랐거든요. 근데 유튜브라는 거는 자격증이 필요 없고 누구나 할 수 있기 때문에 다 도전을 하시면 무조건 됩니다.
> 제가 머리 쓸 거는 하나도 없고요.
❗ 클로드 코드 창 10개를 동시에 띄워 대본 10편을 병렬 생성하면 총 2시간, 편당 12분 소요.
❗ 130만 뷰 영상 하나로 558만 원을 벌었으며, 해당 영상은 100% AI 자동 제작.
❗ 지식·과학 채널의 RPM이 4,000원을 넘어, 15~20분짜리 영상임에도 높은 단가를 유지.

## 📚 핵심 용어
- **클로드 코드:** VS Code에서 Claude AI를 에이전트처럼 실행해 웹 서치·논문 인용까지 포함한 대본을 자동 작성하는 도구. / 조교에게 '이 주제 조사해서 원고 써줘'라고 시키면 도서관에서 논문 찾아 30분 만에 초고를 가져오는 것과 같다. / 일반 Claude 웹 채팅은 매번 요구사항을 입력해야 하지만, 클로드 코드는 채널 설정을 기억하고 서치까지 자동으로 수행해 대본 시간을 5시간→12분으로 단축한다.
- **RPM:** 유튜브에서 조회 1,000회당 크리에이터에게 실제 지급되는 광고 수익 금액. / 편의점 진열 위치처럼, 광고주가 원하는 채널(지식·과학)일수록 더 비싼 자리값을 받는다. / 조회수(뷰)는 방문자 수, RPM은 방문자 한 명이 남기는 매출. 조회수가 같아도 RPM이 높으면 수익이 몇 배 차이 난다.
- **튜브워커:** 대본 입력부터 TTS 음성·스토리보드·이미지 생성·캡컷 프로젝트 파일 출력까지 AI 영상 제작을 일괄 처리하는 전용 프로그램. / 반죽 넣으면 모양·굽기까지 자동으로 해주는 제빵기처럼, 대본만 넣으면 편집 가능한 영상 파일이 나온다. / 캡컷 단독 사용은 이미지 150장을 수동으로 넣어야 하지만, 튜브워커는 스토리보드·이미지 매칭·TTS를 자동화해 캡컷 프로젝트 파일만 넘겨준다.
- **스토리보드 자동 생성:** 대본의 각 문장을 분석해 장면별로 어울리는 이미지 프롬프트를 자동으로 배정하는 기능. / 영화 감독이 대사마다 '이 장면엔 이런 그림'을 쪽지에 적어두는 콘티 작업을 AI가 대신 해주는 것. / 수동 편집은 대사와 이미지를 사람이 일일이 맞추지만, 스토리보드 자동 생성은 텍스트를 읽고 의미에 맞는 장면을 AI가 직접 배치한다.
