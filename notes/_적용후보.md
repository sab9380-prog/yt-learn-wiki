## 1. settings.json에 3가지 Claude 비용 절감 설정 적용

**🔧 실제로 하는 일**
youtube-learn-auto가 Claude API를 호출할 때 쓰는 settings.json 파일에서 model을 Sonnet으로, maxThinkingTokens를 10000으로, subAgentModel을 Haiku로 설정해서 API 호출 비용을 줄입니다. 영상 요약 지시문 실행 시 더 적은 비용으로 결과를 받게 됩니다.

> 영상 원문: settings.json 파일에서 3가지 비용 절감 설정 적용 (model: Sonnet, maxThinkingTokens: 10000, subAgentModel: Haiku)

**✅ 이걸 하면 좋아지는 것**
매일 2~5개 영상 분석 시 Claude API 호출 비용이 80% 이상 떨어져 운영 비용이 줄어듭니다.

**⚠️ 걱정되는 점**
Sonnet과 Haiku 모델로 바꾸면 분석 정확도가 떨어질 수 있으며, 지금까지의 요약 품질과 비교해봐야 실제 영향을 알 수 있습니다.

**🔎 얼마나 믿을 만한가**
- 바로 코드로 옮길 수 있을 만큼 구체적입니다.
- 여러 영상이 반복해서 다룬 주제라 근거가 두텁습니다.
- 우리 시스템의 한 부분에 닿습니다.

**📎 어디서 나왔나**: [[2026-05-22-Claude-Code-비용-80-절감하는-settings-json]] — Claude Code 비용 80% 절감하는 settings.json 3줄과 14만명이 쓰는 everything-claude-code 설정법
  영상이 이걸 권한 이유: 다음 달 클로드 사용 비용을 80% 이상 절감할 수 있고 즉시 적용 가능

## 2. 옵시디언 참조 호출 규칙 + 3시간 간격 자동 저장

**🔧 실제로 하는 일**
youtube-learn-auto가 위키 노트를 생성할 때, 기존 옵시디언 노트를 자동으로 참조하도록 지시문을 바꾸고, 3시간마다 위키 변경사항을 자동 저장하는 크론잡(또는 Make·n8n 워크플로우)을 Node.js 파이프라인에 연결합니다. 분석 결과가 기존 지식과 자동으로 연결되고 누적됩니다.

> 영상 원문: Claude나 Codex 등 사용 중인 에이전트에 '옵시디언 참조 호출' 규칙을 설정하고, 3시간 간격 자동 저장 크론잡 또는 유사 자동화(Make·n8n 등)를 연결해 테스트 루프 1회 실행

**✅ 이걸 하면 좋아지는 것**
매번 수동 저장하지 않아도 지식이 자동으로 쌓이고, 새 영상 분석 시 이전 학습 내용이 자동으로 참조되어 분석 깊이가 깊어집니다.

**⚠️ 걱정되는 점**
3시간 간격 자동 저장 시 옵시디언 파일이 동시에 여러 곳에서 수정되면 충돌 위험이 있으며, 크론잡 설정 난도가 있어 테스트가 필수입니다.

**🔎 얼마나 믿을 만한가**
- 바로 코드로 옮길 수 있을 만큼 구체적입니다.
- 여러 영상이 반복해서 다룬 주제라 근거가 두텁습니다.
- 우리 시스템의 한 부분에 닿습니다.

**📎 어디서 나왔나**: [[2026-06-23-자신-있게-말씀드립니다-현-시점-AX는-이-영상으로-종결합니다]] — 자신 있게 말씀드립니다 현 시점 AX는 이 영상으로 종결합니다
  영상이 이걸 권한 이유: 수동 저장에만 의존하면 맥락 누락이 생기고, 자동화가 있어야 지식이 복리로 쌓이는 구조가 실제로 작동한다.

## 3. 영상 요약 정확도 베이스라인 테스트 20~30개 질문

**🔧 실제로 하는 일**
youtube-learn-auto의 영상 요약 지시문이 정말 잘 작동하는지 측정하기 위해, 정답을 이미 아는 테스트 질문 20~30개를 만들어 현재 시스템의 정확도를 수치로 기록합니다. 나중에 지시문을 바꾸거나 문서를 업데이트했을 때 개선 여부를 비교할 기준이 됩니다.

> 영상 원문: 정답을 아는 테스트 질문 20~30개 만들어 AI 정확도 베이스라인 측정 — ⏰ 2주 내 · ⚡ 1~2시간

**✅ 이걸 하면 좋아지는 것**
영상 요약 결과가 실제로 좋아지고 있는지 객관적으로 판단할 수 있으므로, 앞으로의 개선 작업이 효과가 있는지 없는지 명확히 알 수 있습니다.

**⚠️ 걱정되는 점**
테스트 질문 작성이 2주 내 완료되어야 하고, 정답을 미리 정해야 하는데 시간이 들 수 있습니다.

**🔎 얼마나 믿을 만한가**
- 바로 코드로 옮길 수 있을 만큼 구체적입니다.
- 여러 영상이 반복해서 다룬 주제라 근거가 두텁습니다.
- 우리 시스템의 한 부분에 닿습니다.

**📎 어디서 나왔나**: [[2026-06-25-진짜는-에이전트가-아니라-스킬-이었다]] — 진짜는 에이전트가 아니라 '스킬'이었다
  영상이 이걸 권한 이유: 측정 없이는 개선을 확인할 수 없고, 문서 업데이트 효과도 검증 불가하다.
