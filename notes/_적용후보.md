## 1. Claude에게 최적 분석 지시문을 직접 만들게 하기

> 원문: Anthropic 공식 Claude 5 프롬프트 가이드 페이지를 열고, Claude에게 링크를 던져 '내 업무(예: 상품 설명 자동 생성 / 웹소설 기획서 작성)에 맞는 시스템 프롬프트를 만들어 달라'고 요청해 본다. — ⏰ 이번 주 · ⚡ 30분

Claude 공식 가이드를 Claude 자신에게 읽혀서 우리 시스템에 맞는 더 나은 프롬프트를 만들게 하자는 것.

**✅ 이걸 하면 좋아지는 것**
지금의 분석 지시문(①번 개선점)을 더 정확하고 효율적으로 바꿀 수 있어, 같은 시간에 더 질 좋은 학습 노트가 생긴다.

**⚠️ 걱정되는 점**
새 프롬프트를 실제로 적용해 결과를 비교해 봐야 효과를 알 수 있으므로, 시간 투자 대비 개선 폭이 미지수입니다.

**🔎 얼마나 믿을 만한가**
- 바로 코드로 옮길 수 있을 만큼 구체적입니다.
- 여러 영상이 반복해서 다룬 주제라 근거가 두텁습니다.

## 2. Claude Code로 자막 자동 처리 도구 만들기
