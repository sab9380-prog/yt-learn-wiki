# Anthropic이 직접 공개한 5가지 비밀, 모델보다 이게 더 중요합니다

## 🧠 이해 (Understand)
- **Summary:** 엔트로픽에서 공개한 대규모 코드베이스에서 클로드 AI를 효과적으로 활용하는 방법을 설명한다. 기존 AI들이 사전 색인을 만들어 관리하는 방식과 달리, 클로드는 실시간으로 탐색하는 방식을 채택한다. 5가지 핵심 도구(클로드.md 매뉴얼, 훅스 자동화, 스킬스 전문가이드, 플러그인 패키지, LSP 검색시스템)를 소개하고, 성공한 기업들의 3가지 공통점(정기점검, 책임자 지정, AI운영매니저 신설)을 분석한다. 마지막으로 실제 도입을 위한 5단계 실행 방안을 제시한다.
- **Core Message:** 대규모 코드베이스에서 클로드 AI를 성공적으로 활용하려면 5가지 도구 셋업과 체계적인 관리 전략이 필수다.
> 신입사원이 회사 구조 모르면 헤멜 수 있잖아요
> 김대리는 잘 셋업해 놓고 일 잘하는데 옆부서는 아무도 모르는 상황
> 똑똑해진 AI 발목을 잡는 거예요
❗ 수백만 줄짜리 코드를 다루는 회사들이 실제로 존재한다
❗ 성공한 기업들은 AI 운영 매니저라는 새로운 직책을 만들어서 운영한다
❗ 클로드는 사전 색인을 만들지 않고 실시간으로 탐색하는 방식을 사용한다

## 📚 핵심 용어
- **클로드.md:** AI가 코드 작업 시 가장 먼저 읽는 회사 규칙과 가이드라인이 담긴 매뉴얼 파일 / 신입사원이 첫 출근날 받는 회사 소개서나 업무 매뉴얼과 같다. 복장 규정, 보고 절차 같은 기본 규칙을 담고 있다. / 기존 두꺼운 종합 매뉴얼과 달리 부서별로 나눈 작은 매뉴얼 방식을 채택해 AI가 혼란 없이 집중할 수 있게 한다.
- **훅스(Hooks):** 특정 상황이 발생하면 자동으로 실행되는 규칙이나 검수 프로그램 / 현관문 자동 센서처럼 사람이 들어오면 불이 켜지듯, AI가 작업하면 자동으로 오타나 규칙 위반을 검사해준다. / 매번 수동으로 확인 요청하는 것과 달리 100% 자동화되어 실수나 누락이 발생하지 않는다.
- **LSP:** 코드에서 같은 이름의 함수나 변수를 정확히 구분해서 찾아주는 정밀 검색 시스템 / 큰 회사에 김민수가 50명 있을 때 '3층 영업팀 김민수'처럼 정확한 위치를 짚어주는 사내 전화번호부와 같다. / 일반 검색은 같은 이름을 모두 나열하지만, LSP는 맥락을 파악해 정확히 원하는 대상만 찾아준다.
