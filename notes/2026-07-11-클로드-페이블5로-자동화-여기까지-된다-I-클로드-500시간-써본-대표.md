# 클로드 페이블5로 자동화 여기까지 된다? I 클로드 500시간 써본 대표 후기

## 🧠 이해 (Understand)
- **Summary:** 패션/이커머스 회사 대표가 AI 이미지 생성 워크플로우의 병목(모델 캐스팅 시간 과다)을 해결하기 위해 '모델 스튜디오' 웹앱을 구축한 사례를 공유한다. Claude Sonnet/Opus(프롬프트 생성·분석), Fable 5(웹사이트 설계·구현), Flux Fill(이미지 생성) 세 도구를 조합해 내부 자동화 툴을 만들었다. 핵심은 실무를 직접 해보며 병목 구간을 찾고, 그 부분만 AI로 자동화하는 접근법이다. 모델 선택도 작업 복잡도에 따라 Sonnet/Opus/Fable을 구분해 쓰며 토큰 비용을 최적화한다. AI 시대에 중요한 것은 도구 숙련도보다 '어떤 페인포인트를 해결해 수익화할지'라는 비즈니스 감각이라고 강조한다.
- **Core Message:** AI 이미지 워크플로우의 병목을 직접 체험으로 찾아내고, 여러 AI 도구를 역할별로 조합해 내부 자동화 웹앱으로 해결한 실전 사례.
> AI로 웬만한 걸 다 실현화할 수 있는 시대가 되었다. 어떤 아이디어로 사람들의 불편함과 페인포인트를 해결해서 내가 그걸로 돈을 벌 수 있을지가 더 중요해졌다.
> 제가 이걸 직접 뛰어봐야지 어느 부분에서 제일 오래 병목 구간이 생기는지를 파악할 수 있기 때문이거든요.
> 페이블 5한테 처음에 큰 틀은 구축해 주고, 수정은 오퍼스한테 시키는 거죠.
❗ AI 이미지 모델은 빅데이터 기반이라 특정 '전형적 미남미녀' 얼굴만 반복 생성되어, 의도적으로 '뻔하지 않은 호감형'을 뽑는 것이 핵심 기술이 되었다.
❗ Fable 5의 무료/저렴 사용 기간이 2025년 7월 7일까지로 한정되어 있으며, 이후에는 토큰 비용이 크게 올라간다고 언급되었다.
❗ AI 모델 턴어라운드 기본 의상으로 '흰티+청바지'를 표준화한 이유가, 심플한 옷일수록 이후 다른 의상 합성이 쉬워지기 때문이라는 실무 노하우가 있었다.

## 📚 핵심 용어
- **클로드 스킬:** Claude 채팅 내에서 슬래시(/)로 호출하는 재사용 가능한 프롬프트 템플릿 단위. / 엑셀 매크로처럼, 자주 쓰는 작업을 버튼 하나로 실행하는 저장된 명령어 묶음이다. / 스킬은 Claude 채팅 안에서만 동작하지만, Fable로 구현한 웹앱은 누구나 브라우저에서 바로 쓸 수 있다.
- **턴어라운드(turn-around):** AI 영상·이미지의 모델 일관성을 위해 정면·측면·후면·클로즈업 등 여러 각도를 한 세트로 뽑는 작업. / 쇼핑몰 상품 360도 뷰처럼, 같은 모델을 모든 방향에서 찍어 다른 씬에서도 동일인임을 보장한다. / 단순 단일 이미지 생성은 한 컷이지만, 턴어라운드는 영상 제작용으로 각도별 세트를 한꺼번에 확보하는 것이 목적이다.
- **Fable 5:** Claude 계열의 코딩·빌딩 특화 AI로, 프롬프트만으로 웹사이트 설계와 구현을 동시에 수행한다. / 설계도를 그리고 직접 집도 짓는 건축가처럼, 기획과 시공을 혼자 다 해준다. / Claude Opus는 복잡한 분석·추론에 강하고, Fable 5는 코드 기반 웹 구현에 특화되어 있다.
- **프롬프트 분해:** 이미지나 제품 사진을 AI가 텍스트 속성으로 파싱한 뒤, 그 텍스트로 새 이미지 생성 프롬프트를 만드는 방식. / 요리 사진을 보고 재료 목록을 먼저 뽑아낸 뒤 레시피를 쓰는 것과 같다. / 이미지를 그대로 레퍼런스로 넘기면 모델이 제품을 '들고 있는' 장면만 나오지만, 분해 후 재생성하면 제품 속성에 맞는 모델 컨셉이 나온다.

- [ ] Claude 스킬에 AI 모델 프롬프트 템플릿(턴어라운드 각도별, 캠페인 브리프 입력 포함)을 구축하고, Fable 5로 사내 웹앱 프로토타입을 만든다. — ⏰ 2주 내 (Fable 5 요금 변경 전) · ⚡ 1~2일
  - 담당: 나 + 내부 PM (검토)
  - 이유: 반복 프롬프트 입력과 복붙 작업을 없애면 모델 캐스팅 시간이 대폭 단축되고 PM도 독립적으로 사용 가능해진다. Fable 5 저렴한 구간(2025.07.07 이전) 활용 시 비용 절감 효과도 있다.
- 자료: Claude Skills (claude.ai 내 슬래시 커맨드) — 실제 존재, 유료 플랜 필요

- 자료: Fable 5 (Claude 계열 빌딩 AI) — 확인 필요: 공식 명칭·접속 경로 영상에서 미언급, Anthropic 공식 사이트에서 확인 필요
- 자료: Claude API (anthropic.com) — 프롬프트 분해·분석 연동용, 실제 존재
