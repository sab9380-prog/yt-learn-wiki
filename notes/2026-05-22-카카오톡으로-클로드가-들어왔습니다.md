# 카카오톡으로 클로드가 들어왔습니다

## 🧠 이해 (Understand)
- **Summary:** Claude Computer Use(코워크) 기능을 활용해 매일 아침 자동으로 경제 뉴스를 수집하고, 보고서를 작성해 구글 드라이브에 업로드한 후 카카오톡으로 링크를 전송하는 완전 자동화 시스템을 구축하는 방법을 단계별로 설명한다. 기존 Claude가 답변만 주는 도구였다면, 코워크는 나를 대신해 일하는 직원을 만드는 도구로, 웹 스크래핑부터 파일 생성, 클라우드 업로드, 메신저 전송까지 5단계를 하나의 명령으로 자동 실행한다. MCP(Model Context Protocol)를 통해 구글 드라이브와 macOS 자동화를 연결하고, 스케줄러로 매일 정해진 시간에 실행되도록 설정하는 전체 워크플로우를 시연한다.
- **Core Message:** Claude 코워크는 단순 답변 도구가 아니라 나를 대신해 복잡한 업무 프로세스를 자동으로 처리하는 AI 직원을 만드는 도구이다.
> 지금까지 클로드는 백과사전이었어요. 근데 코워크는 신입 직원이에요. 시키면 일을 해요.
> 코워크의 진짜 가치는 단일 작업이 아니라 워크플로우예요.
> 도구 하나를 잘 쓰는 게 아니라 도구들을 연결해서 시스템을 설계하는 거예요.
❗ 카카오톡은 개인용 API가 닫혀있어서 마우스와 키보드 조작으로만 자동화가 가능하다
❗ Claude 코워크는 지정된 폴더만 접근 가능하고 컴퓨터 전체에 접근하지 않는다
❗ 하나의 명령으로 웹스크래핑→보고서 작성→클라우드 업로드→메신저 전송까지 5단계를 자동 처리한다

## 📚 핵심 용어
- **Claude Computer Use(코워크):** Claude가 컴퓨터를 직접 조작해서 업무를 대신 처리하는 기능. / 백과사전(기존 Claude)이 신입 직원으로 바뀐 것. 물어보면 답하는 게 아니라 시키면 일을 해준다. / 기존 Claude는 답변만 주는 도구, 코워크는 실제로 일을 처리하는 직원. 내가 직접 해야 하느냐 안 해도 되느냐의 차이.
- **MCP(Model Context Protocol):** AI와 외부 서비스를 연결하는 통일된 규격. / USB-C 충전선처럼 하나의 규격으로 모든 기기를 연결. 예전엔 기기마다 충전선이 달랐지만 이제 하나로 통일. / 기존엔 서비스마다 연결 방식이 제각각이었지만, MCP는 모든 서비스를 같은 방식으로 연결 가능.
- **웹스크래핑:** 웹사이트에서 자동으로 정보를 수집하는 기술. / 누가 신문을 통째로 스캔해서 들고 와주는 것. 나는 중요한 기사만 골라보면 된다. / 사람이 눈으로 하나씩 보는 것과 달리, 페이지 전체를 한 번에 읽어와서 몇 초 만에 정리.
- **워크플로우 자동화:** 여러 단계의 업무를 하나의 명령으로 연결해서 자동 실행하는 시스템. / 자동차 부품들을 연결해서 완성된 자동차를 만드는 것. 각 부품은 별거 아니지만 연결하면 완전히 다른 가치. / 단일 작업 자동화는 부품 하나 만들기, 워크플로우는 부품들을 연결해서 완전한 시스템 구축.
