# 웹 개발 (web-dev) 종합 노트

## 핵심 구조: 3층 아키텍처

웹 개발의 전체 그림은 **프론트엔드 → 백엔드 → 데이터베이스**의 흐름이다. [[2026-05-22-프론트엔드-백엔드-데이터베이스-전체를-20분만에-보이게-해드립니다]]

- **프론트엔드**: HTML(뼈대) + CSS(옷) + JavaScript(동작)로 사용자 화면을 구성 [[2026-05-29-웹-개발의-핵심을-단-7시간-만에-끝내기]]
- **연결고리**: API가 프론트-백엔드를 이어주고, DNS가 도메인→IP를 변환 [[2026-05-22-프론트엔드-백엔드-데이터베이스-전체를-20분만에-보이게-해드립니다]]
- **백엔드**: WAS가 로직을 처리하고 DB에 CRUD 작업 수행 [[2026-05-22-프론트엔드-백엔드-데이터베이스-전체를-20분만에-보이게-해드립니다]]

---

## 코딩 ≠ 개발 전체: 노트들이 공통으로 경고하는 것

세 노트가 한 목소리로 강조하는 것: **코드를 짜는 것은 시작일 뿐**이다.

| 영역 | 내용 |
|------|------|
| **배포** | 코드를 서버에 올려야 실제 사용자가 접근 가능 [[2026-05-22-바이브-코딩을-시작하는-분들-끝까지-보고-하세요]] |
| **보안** | AI는 기능은 만들어주지만 RLS·Rate Limit·API 키 관리는 사람이 직접 체크 [[2026-05-22-바이브코딩-보안-실수-3가지]] |
| **AI 관리** | 클로드.md·훅스·LSP로 AI 도구 자체를 체계적으로 운영해야 함 [[2026-05-22-Anthropic이-직접-공개한-5가지-비밀-모델보다-이게-더-중요합니다]] |

> "코딩은 전체의 10%. 설정과 운영이 나머지 90%다" [[2026-05-22-바이브코딩-보안-실수-3가지]]

---

## 관점 차이: 입문 vs 실전

- **입문 관점**: HTML·CSS·JS 문법만 익혀도 간단한 웹페이지 제작 가능 [[2026-05-29-웹-개발의-핵심을-단-7시간-만에-끝내기]]
- **실전 관점**: AI가 코드를 써줘도 배포·보안·아키텍처 이해 없이는 진짜 서비스 불가 [[2026-05-22-바이브-코딩을-시작하는-분들-끝까지-보고-하세요]] [[2026-05-22-바이브코딩-보안-실수-3가지]]

---

## 주의점

- 프론트엔드에 API 키를 두면 **누구나 추출 가능** → 반드시 백엔드에만 보관 [[2026-05-22-바이브코딩-보안-실수-3가지]]
- AI의 "완료"는 기능 동작 기준, 나의 "완료"는 보안까지 포함한 기준이어야 함 [[2026-05-22-바이브코딩-보안-실수-3가지]]

---

## 한 줄 정의

> 웹 개발이란 HTML·CSS·JS로 화면을 만들고, API로 서버와 연결하며, 배포·보안·운영까지 책임지는 전체 과정이다.
