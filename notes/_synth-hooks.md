# 훅스 (Hooks) — 종합 노트

## 핵심 개념 (공통 이해)

모든 노트가 훅스를 **"특정 조건/이벤트 발생 시 자동으로 다른 기능을 실행시키는 트리거 시스템"** 으로 일관되게 설명합니다. 사람이 직접 버튼을 누르지 않아도, 조건이 충족되면 미리 정해둔 작업이 자동 실행됩니다. [[2026-05-22-Anthropic이-직접-공개한-5가지-비밀-모델보다-이게-더-중요합니다]] [[2026-05-22-클로드-코드-안에서-코덱스를-사용하는-코덱스-플러그인-세팅-가이드]]

> 현관 자동센서처럼 — 사람이 들어오면 불이 저절로 켜지듯, AI가 작업하면 자동으로 검사·실행이 따라온다.

## 실전 적용

- **슬래시 명령 vs 훅스의 차이**: 슬래시 명령은 사용자가 직접 실행, 훅스는 조건 충족 시 자동 실행 — 사람 개입이 없으므로 실수·누락이 원천 차단됩니다. [[2026-05-22-클로드-코드-안에서-코덱스를-사용하는-코덱스-플러그인-세팅-가이드]]
- **실제 효과**: 매번 수동으로 "이 파일 규칙 검사해줘"라고 요청하지 않아도 AI 작업 시마다 자동 검수가 붙습니다. [[2026-05-22-Anthropic이-직접-공개한-5가지-비밀-모델보다-이게-더-중요합니다]]
- **맥락 망각 해결**: 오토 컨텍스트 훅은 AI가 시작될 때 프로젝트 정보를 자동으로 밀어넣어, AI가 기억을 참조하는 것을 "까먹을 수 없게" 만듭니다. [[2026-05-22-세계가-주목한-Karpathy-LLM-Wiki-진짜-돌아가는-도구를]]

## 주의점

훅스 단독으로는 완전하지 않습니다. 실전에서는 **에이전트.md(규칙) + 훅스(자동 실행) + MCP(연결) + 서브에이전트(병렬 처리)** 가 묶여야 제 힘을 냅니다 — 이것이 플러그인이라는 패키지 개념입니다. [[2026-05-22-클로드-코드-안에서-코덱스를-사용하는-코덱스-플러그인-세팅-가이드]]

---

## 한 줄 정의

> **훅스(Hooks)란, 특정 조건이 충족되면 사람 개입 없이 자동으로 정해진 작업(검수·맥락 주입·기능 실행)을 트리거하는 AI 자동화의 방아쇠다.**
