# 웹 크롤링 (Web Crawling) 종합

## 핵심 공통 메시지

세 노트 모두 **"수작업 반복 수집 → 자동화"** 라는 같은 목적을 향한다. 웹 크롤링은 사람이 눈으로 보던 웹페이지 정보를 프로그램이 대신 긁어오는 기술이며, 이를 통해 시간 절약·업무 자동화·심지어 수익 창출까지 가능하다 [[2026-05-22-웹크롤링-비법-대공개-데이터-수집-기초부터-돈버는-전략까지-한번에-배우기]] [[2026-05-22-카카오톡으로-클로드가-들어왔습니다]].

---

## 서로 다른 관점·강조점

| 노트 | 접근법 | 핵심 강조 |
|---|---|---|
| 웹크롤링 비법 | 직접 코드 작성 (Python, BeautifulSoup) | 기초 원리 이해, 부업 활용 [[2026-05-22-웹크롤링-비법-대공개-데이터-수집-기초부터-돈버는-전략까지-한번에-배우기]] |
| 인세인 서치 | 플러그인으로 코드 불필요 | 봇 차단 우회, AI 에이전트가 직접 수행 [[2026-06-25-시즌-3-온갖-크롤링-코드-안녕-공개된-페이지를-모두-긁어버리는]] |
| 카카오톡+클로드 | 크롤링을 워크플로우의 일부로 | 수집 후 → 보고서 → 업로드 → 전송까지 연결 [[2026-05-22-카카오톡으로-클로드가-들어왔습니다]] |

즉, **기초 → 자동화 도구 → 시스템 연결**로 난이도와 활용도가 계단식으로 올라간다.

---

## 실전 적용

- **가장 빠른 진입**: 클로드 코드 + 인세인 서치 플러그인 설치 → 쿠팡·네이버 상품 데이터 CSV 수집 (추가 비용 없음) [[2026-06-25-시즌-3-온갖-크롤링-코드-안녕-공개된-페이지를-모두-긁어버리는]]
- **실력 쌓기**: Python + BeautifulSoup으로 직접 코딩, 외주로 10~60만원 수입 가능 [[2026-05-22-웹크롤링-비법-대공개-데이터-수집-기초부터-돈버는-전략까지-한번에-배우기]]
- **고도화**: 수집한 데이터를 보고서 작성 → 드라이브 업로드 → 카카오톡 전송까지 1개 명령으로 자동화 [[2026-05-22-카카오톡으로-클로드가-들어왔습니다]]

---

## 상충·주의점

- **봇 탐지 장벽**: 쿠팡·네이버 등 주요 사이트는 AI 접근을 차단한다. 인세인 서치는 내부 API 호출 → Playwright 브라우저 자동화 순으로 단계적으로 우회하며, **공개 페이지에만** 적용한다 (로그인·결제 페이지 제외) [[2026-06-25-시즌-3-온갖-크롤링-코드-안녕-공개된-페이지를-모두-긁어버리는]]
- **코드 직접 작성 vs 도구 활용**: 원리를 모르면 도구가 막혔을 때 속수무책. 인세인 서치 같은 도구의 등장으로 "크롤링 강의 자체가 필요 없어질 수 있다"는 평가도 나오지만 [[2026-06-25-시즌-3-온갖-크롤링-코드-안녕-공개된-페이지를-모두-긁어버리는]], 기초 이해는 여전히 문제 해결에 유용 [[2026-05-22-웹크롤링-비법-대공개-데이터-수집-기초부터-돈버는-전략까지-한번에-배우기]]

---

## 한 줄 정의

> **웹 크롤링이란, 사람이 눈으로 보는 공개 웹페이지의 정보를 프로그램이 자동으로 긁어오는 기술로, 코드 직접 작성부터 AI 플러그인·워크플로우 자동화까지 다양한 방식으로 활용할 수 있다.**
