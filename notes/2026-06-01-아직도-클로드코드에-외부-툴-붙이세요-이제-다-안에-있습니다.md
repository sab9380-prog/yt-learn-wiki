# 아직도 클로드코드에 외부 툴 붙이세요? 이제 다 안에 있습니다

## 🧠 이해 (Understand)
- **Summary:** 클로드의 새로운 기능인 '다이나믹 워크플로우'를 소개하는 영상입니다. 이 기능은 클로드가 자바스크립트 스크립트를 작성하여 수십개의 하위 에이전트를 동시에 지휘하는 시스템입니다. 기존에는 외부 도구로 해야 했던 멀티 에이전트 작업을 클로드 내부에서 처리할 수 있게 되었고, 백그라운드에서 실행되므로 다른 작업을 병행할 수 있습니다. 특히 리팩토링이나 버그 수정 등 코드 작업에서 뛰어난 성능을 보이며, 에이전트들이 서로 검증하여 품질을 높입니다. 이는 클로드가 외부 하네스(보조 도구)를 내재화하며 완성형 작업 환경으로 진화하는 신호로 해석됩니다.
- **Core Message:** 클로드가 외부 도구에 의존하지 않고 자체적으로 복잡한 작업을 처리할 수 있는 완성형 플랫폼으로 진화하고 있다는 신호입니다.
> 바깥에 붙이던 것들이 하나둘씩 클로드 코드 안으로 빨려 들어오고 있어요
> 똑똑한 한 명이 머리 싸매고 다 하는게 아니라, 똑똑한 한 명이 똑똑한 여러 명을 지휘하는 구조로 바뀌는 거예요
> 바깥 앱들이 본체 기능이 되는 길이에요
❗ 한 번에 최대 16개 에이전트가 동시 실행 가능
❗ 한 작업에 최대 100만개까지 에이전트 사용 가능
❗ 리팩토링과 버그 수정은 뛰어나지만 리서치는 토큰 대비 효과가 떨어짐

## 📚 핵심 용어
- **하네스:** AI 도구를 감싸서 더 큰 일을 시키게 만드는 외부 관리 체계 / 똑똑한 신입사원에게 매니저와 결재라인, 매뉴얼을 붙여주는 것과 같다 / 기존 하네스는 외부 도구였지만, 다이나믹 워크플로우는 이를 내재화한 것
- **다이나믹 워크플로우:** 클로드가 자바스크립트 스크립트로 여러 에이전트를 지휘하며 백그라운드에서 실행하는 시스템 / 현장소장이 여러 명의 목수를 동시에 감독하여 큰 건축물을 짓는 것과 같다 / 기존 순차적 에이전트 vs 다이나믹 워크플로우 - 하나는 한 명씩 시키는 것, 하나는 여러 명을 동시에 지휘하는 것
- **컨텍스트 윈도우:** AI가 한 번에 기억할 수 있는 정보량의 한계 / 책상 위 공간이 정해져 있어서 새 문서를 올리면 예전 것을 치워야 하는 것과 같다 / 기존 방식은 모든 결과가 쌓여서 금방 꽉 차지만, 워크플로우는 중간 결과를 별도 저장하여 최종 결과만 올린다
- **교차 검증:** 여러 에이전트가 서로의 결과를 검토하고 반박하여 정확성을 높이는 과정 / 한 사람이 쓴 보고서를 여러 동료가 검토하여 오류를 찾는 것과 같다 / 혼자 검사 vs 교차 검증 - 하나는 자기 확인, 하나는 동료 리뷰 시스템
