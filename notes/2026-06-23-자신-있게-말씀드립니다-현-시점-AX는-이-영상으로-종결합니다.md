# 자신 있게 말씀드립니다 현 시점 AX는 이 영상으로 종결합니다

[[_category-일반학습]]

## 🧠 이해 (Understand)
- **Summary:** 이 영상은 옵시디언을 AI 에이전트의 외부 메모리 시스템으로 활용하는 방법에 대한 후속 Q&A 및 업그레이드 내용을 다룹니다. 맥락 저장 시점(수동/자동), Raw·Wiki·Conversation의 분류 기준, 에이전트의 맥락 호출 방식, 유사 내용 간 링크 연결 등 이전 영상 질문에 답변합니다. 사람이 직접 작성한 도메인 지식(이력서, 보고서 등)도 옵시디언에 누적하면 에이전트가 두 개의 메모리(단기+장기)를 갖게 된다는 개념을 제안합니다. 레퍼런스 수집→해체→규칙 파악→모듈화→스킬 생성의 학습 단계를 통해 에이전트가 도메인 전문가로 성장하는 구조를 설명합니다. 스킬들이 링크로 연결되면 자동으로 '하네스(Harness)'가 형성되고, 크론잡을 통해 지식 축적이 복리로 가속화된다고 봅니다. 로컬 옵시디언을 넘어 클라우드(자체 ERP)로 확장하여 이메일·노션·구글 캘린더를 연동하고, 텔레그램·슬랙 게이트웨이로 외부에서도 업무 지시가 가능한 AI 네이티브 환경을 구축했습니다. 업무 성과를 주간·월간·연간 단위로 자동 정리하는 기능도 포함되며, 중소기업 AX 도입 컨설팅 의향도 밝힙니다.
- **Core Message:** 옵시디언을 에이전트와 사람이 함께 쓰는 누적형 지식 기반으로 만들면, 스킬이 자동으로 연결·강화되어 업무 성장이 복리로 가속화된다.
> 지식은 복리로 쌓이게 되는 구조입니다.
> 저 하나를 이렇게 둘러싸고 에이전트들이 열심히 일을 해 주는 그런 AI 네이티브 환경인 거죠.
> 이 지점이 에이전틱 엔지니어링의 중심이 될 거라고 생각을 합니다.
❗ 에이전트가 크론잡으로 3시간마다 자동으로 옵시디언에 리서치 결과를 저장하도록 설계되어 있다.
❗ 텔레그램으로 명함 사진을 보내면 OCR로 원본과 텍스트를 분리해 거래처 정보로 자동 등록된다.
❗ 업무 성과가 주간·월간·연간 단위로 자동 정리되며, 직원 계정 등록만 하면 해당 직원 성과도 자동 분류된다.

## 📚 핵심 용어
- **하네스(Harness):** 개별 스킬들이 링크로 연결되어 자동으로 묶인 통합 역량 구조체. / 레고 블록 여러 개를 조립하면 더 큰 구조물이 되듯, 스킬들이 연결되면 혼자서는 못 하는 일을 함께 처리한다. / 개별 스킬은 단일 도구, 하네스는 도구함 전체다. 스킬은 특정 작업 하나만, 하네스는 여러 작업을 연속 실행한다.
- **Raw / Wiki / Conversation 분류:** 옵시디언 저장소를 원본 문서(Raw), 에이전트 생성 지식(Wiki), 대화 기록(Conversation)으로 나누는 체계. / 서류함을 원본 계약서 칸, 정리 요약본 칸, 회의록 칸으로 나눠두는 것과 같다. / Raw는 손대지 않은 원재료, Wiki는 그것을 가공한 완성품이다. 출처 추적이 필요하면 Raw, 재활용할 지식은 Wiki로 간다.
- **크론잡(Cron Job):** 특정 시간 간격마다 자동으로 반복 실행되도록 예약된 작업. / 매일 아침 6시에 울리는 알람처럼, 시간이 되면 사람 개입 없이 지정된 일을 자동으로 수행한다. / 수동 저장은 내가 버튼을 누를 때만 저장, 크론잡은 내가 자리를 비워도 3시간마다 알아서 저장한다.
- **AX(AI Transformation):** 업무 전반을 AI 에이전트 중심으로 재설계해 운영하는 기업 전환 방식. / 공장 자동화가 사람 손 대신 기계를 넣은 것처럼, AX는 사무 업무에 AI를 넣어 흐름 자체를 바꾼다. / 단순 AI 도구 도입은 계산기를 쓰는 것, AX는 업무 프로세스 전체를 재설계하는 것이다.
