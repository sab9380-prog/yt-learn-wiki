1. **모델을 작업 복잡도에 맞게 골라 써라** — 단순 반복은 Sonnet, 복잡한 분석·계획은 Opus, 코드 구현은 Fable 5 [[2026-07-11-클로드-페이블5로-자동화-여기까지-된다-I-클로드-500시간-써본-대표]] [[2026-07-04-Claude-Fable-5-Use-Cases-You-Must-Do]]
2. **목적만 명확히 전달하라** — 세부 방법을 지시하지 않아도 Claude가 스스로 판단·피드백하며 결과를 낸다 [[2026-07-08-클로드-페이블5-100-사용-방법]]
3. **클로드 스킬로 반복 작업을 템플릿화하라** — 자주 쓰는 프롬프트를 스킬로 등록하면 엑셀 매크로처럼 버튼 하나로 실행 가능 [[2026-07-04-Claude-Fable-5-Use-Cases-You-Must-Do]] [[2026-07-11-클로드-페이블5로-자동화-여기까지-된다-I-클로드-500시간-써본-대표]]

## 주의점·상충

- Fable 5는 강력하지만 **주간 사용량 50% 한도 제한**이 있어, 프롬프트 효율(PRD 사전 작성 등)이 핵심 변수 [[2026-07-04-Claude-Fable-5-Use-Cases-You-Must-Do]]
- Claude가 이미지 생성 시 **빅데이터 기반 '전형적 미남미녀'만 반복** 생성하는 한계가 있어, 의도적으로 다양성을 지시해야 함 [[2026-07-11-클로드-페이블5로-자동화-여기까지-된다-I-클로드-500시간-써본-대표]]
- AI 도구 숙련도보다 **"어떤 페인포인트를 해결할지"라는 비즈니스 감각**이 더 중요하다는 점이 실전 사례에서 강조됨 [[2026-07-11-클로드-페이블5로-자동화-여기까지-된다-I-클로드-500시간-써본-대표]]
