# Ralph Loop 종합 정리

## 핵심 (공통으로 말하는 것)

세 노트 모두 같은 구조를 설명한다: **목표 설정 → AI가 실행 → 검증 → 반복 → 목표 달성**. 사람이 매 단계 개입하지 않고, AI가 스스로 루프를 돌아 완성에 도달한다 [[2026-05-22-Codex의-이-기능은-반드시-쓰셔야-합니다-goal-마스터코스]] [[2026-05-22-클로드-코드-그냥-돌리면-실패합니다-feat-Ralph-Loop]].

이름의 유래는 심슨의 바보 캐릭터 Ralph Wiggum, 고안자는 호주 농부 Jeffrey Huntley [[2026-05-22-Codex의-이-기능은-반드시-쓰셔야-합니다-goal-마스터코스]].

## 실전 적용

- **사람의 역할 변화:** 루프 *안*에서 작업자가 아니라, 루프 *위*에서 목표·기준·환경을 설계하는 코치 [[2026-06-09-AI를-자동으로-진화시키는-법]]
- **성공 조건 3가지:**
  1. 명확한 완료 조건 — AI가 스스로 "끝났다"를 판단할 기준 [[2026-05-22-클로드-코드-그냥-돌리면-실패합니다-feat-Ralph-Loop]]
  2. 파일 분리 — 정보를 통째로 넣지 말고 4개 파일(PROMPT.md·specs·실행계획·AGENTS.md)로 분리 [[2026-05-22-클로드-코드-그냥-돌리면-실패합니다-feat-Ralph-Loop]]
  3. 측정 기준 고정 — 같은 시험지(골든 셋)로 매번 비교해야 개선이 보임 [[2026-06-09-AI를-자동으로-진화시키는-법]]
