# 프론트엔드 백엔드 데이터베이스 전체를 20분만에 보이게 해드립니다. | 바이브코딩 하는 분 꼭 끝까지 들어보세요.

## 🧠 이해 (Understand)
- **Summary:** IT 시스템의 전체 구조를 프론트엔드와 백엔드로 나누어 상세히 설명하는 영상입니다. 프론트엔드는 웹(HTML, CSS, JavaScript)과 앱으로 구분되며, 각각 HTTP/HTTPS 프로토콜을 통해 백엔드와 통신합니다. 백엔드는 웹서버(정적 파일 제공)와 WAS(동적 처리)로 나뉘며, 데이터베이스와 연동하여 CRUD 작업을 수행합니다. 사용자가 버튼을 클릭하면 API 호출이 일어나고, 서버는 SQL을 통해 데이터베이스에서 정보를 조회한 후 JSON 형태로 응답하여 화면에 표시하는 전체 흐름을 설명합니다.
- **Core Message:** 대부분의 IT 시스템은 프론트엔드가 API를 통해 백엔드 서버와 통신하고, 서버는 데이터베이스에서 정보를 조회하여 응답하는 구조로 작동한다.
> 대부분의 서비스는 데이터를 사용하고 있고 데이터를 저장하고 데이터를 보여주는 것들이라고 보셔도 무리가 없습니다
> 서버는 기본적으로 리슨이라고 하는데 대기를 하고 있습니다
> 모든 통신이 클라이언트가 서버로 요청을 하고 서버는 응답을 해주는 형태라고 보시면 됩니다

## 📚 핵심 용어
- **WAS (웹 어플리케이션 서버):** 웹서버에 어플리케이션 로직이 추가된 서버로, 데이터베이스와 연동하여 동적 처리를 담당한다. / 웹서버가 도서관 사서라면, WAS는 요청에 따라 책을 찾고 정리해서 맞춤형 자료집을 만들어주는 연구원이다. / 웹서버는 정적 파일만 제공하지만, WAS는 요청에 따라 데이터를 가공하고 조합해서 동적 응답을 생성한다.
- **CRUD:** 데이터베이스의 기본 4가지 작업인 생성(Create), 읽기(Read), 수정(Update), 삭제(Delete)를 말한다. / 노트에 글을 쓰고(생성), 읽고(조회), 지우개로 고치고(수정), 찢어서 버리는(삭제) 것과 같다. / API는 외부와의 소통창구이고, CRUD는 그 안에서 실제로 데이터를 다루는 구체적인 작업이다.
- **API:** 앱과 서버가 데이터를 주고받기 위한 통신 규약과 접점을 말한다. / 은행 창구와 같다. 고객(앱)이 원하는 업무를 말하면 직원(서버)이 정해진 절차대로 처리해준다. / 웹은 HTML 파일을 받지만, API는 JSON 같은 순수 데이터만 주고받아서 앱이 자유롭게 화면을 구성한다.
- **DNS:** 도메인 이름을 실제 서버의 IP 주소로 변환해주는 시스템이다. / 전화번호부와 같다. 사람 이름(도메인)을 알면 실제 전화번호(IP)를 찾아서 연결해준다. / 도메인은 사람이 기억하기 쉬운 이름이고, IP는 컴퓨터가 실제로 찾아가는 주소번호다.
