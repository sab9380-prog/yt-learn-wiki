# 서브 에이전트 (Sub-Agent)

## 핵심 정의 — 모든 노트가 공통으로 말하는 것

**서브 에이전트 = 메인 AI와 독립된 별도 컨텍스트 창을 가진 보조 AI 인스턴스**

메인 에이전트가 모든 중간 과정을 자기 컨텍스트에 쌓는 반면, 서브 에이전트는 맡은 작업의 과정은 자신의 공간에서 처리하고 **결과만 메인에게 전달**한다. [[2026-06-26-100만-토큰시대-앤트로픽이-알려준-클로드코드-컨텍스트-관리법]] [[2026-05-22-100만-토큰시대-앤트로픽이-알려준-클로드코드-컨텍스트-관리법]]

---

## 두 가지 핵심 역할

### 1. 컨텍스트 오염 방지 도구
서브 에이전트의 가장 실용적 용도는 **메인 컨텍스트 보호**다. 복잡하고 지저분한 중간 작업을 서브 에이전트에게 맡기면, 메인 컨텍스트가 깨끗하게 유지되어 성능 저하(컨텍스트 부패)를 막을 수 있다. [[2026-06-26-100만-토큰시대-앤트로픽이-알려준-클로드코드-컨텍스트-관리법]] [[2026-05-22-Claude-Code-비용-80-절감하는-settings-json]]

### 2. 병렬 처리·분업 실행 단위
더 큰 그림에서 서브 에이전트는 **동시에 여러 전문 작업을 처리**하는 팀원이다. 클로드 코드의 다이나믹 워크플로우는 수십~수백 개의 서브 에이전트를 병렬로 생성해 대형 프로젝트를 분산 처리한다. [[2026-07-03-유능한-페이블을-바보로-만들지-마세요-명령은-줄이고-이유를-말하세요]] [[2026-06-04-클로드-코드-Dynamic-Workflow-기능-비교-총정리]] [[2026-05-22-AI-코딩-판이-바뀌었습니다-클로드코드-에이전트뷰-직접-써봤습니다]]
