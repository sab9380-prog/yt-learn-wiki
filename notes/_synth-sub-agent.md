# 서브 에이전트 (Sub-Agent)

## 핵심 정의 — 모든 노트가 공통으로 말하는 것

**서브 에이전트 = 메인 AI와 분리된 독립 컨텍스트를 가진 전문 보조 AI**

메인 에이전트가 특정 작업을 위해 생성하는 하위 AI 인스턴스로, 핵심은 **중간 과정이 메인 컨텍스트를 오염시키지 않는다**는 것이다. 결과만 메인에게 전달하고 서브 에이전트는 사라진다. [[2026-06-26-100만-토큰시대-앤트로픽이-알려준-클로드코드-컨텍스트-관리법]] [[2026-05-22-100만-토큰시대-앤트로픽이-알려준-클로드코드-컨텍스트-관리법]]

---

## 두 가지 핵심 역할

### 1. 컨텍스트 오염 방지 도구
서브 에이전트는 "더러운 작업은 별도 책상에서 하고 결과만 가져오는 직원"이다. 메인 컨텍스트가 과부하되지 않도록 중간 작업을 격리한다. 30~40만 토큰부터 AI 성능이 저하되는 컨텍스트 부패 문제를 구조적으로 해결한다. [[2026-05-22-Claude-Code-비용-80-절감하는-settings-json]] [[2026-05-22-GSD-Superpowers-Claude-Code-중-누가-새로운-AI]]

### 2. 병렬 처리·분업 도구
메인 에이전트 혼자 순차적으로 일하는 대신, 여러 서브 에이전트가 **동시에 다른 작업**을 처리한다. 페이블 5는 수백 개 서브 에이전트를 병렬 운용하며 며칠짜리 프로젝트를 수행하도록 설계됐다. [[2026-07-03-유능한-페이블을-바보로-만들지-마세요-명령은-줄이고-이유를-말하세요]] [[2026-06-04-클로드-코드-Dynamic-Workflow-기능-비교-총정리]]

## 실전 적용

- **비용 절감**: `settings.json`에서 `subAgentModel: Haiku` 설정으로 서브 에이전트만 저렴한 모델 사용 [[2026-05-22-Claude-Code-비용-80-절감하는-settings-json]]
- **검증 습관**: 중요한 결과물은 반드시 별도 새 에이전트(새 대화창)에서 독립 검증 [[2026-07-03-유능한-페이블을-바보로-만들지-마세요-명령은-줄이고-이유를-말하세요]]
- **황금 비율**: 동시 운용 세션은 4~8개가 최적. 그 이상은 관리 비용이 이득을 초과 [[2026-05-22-AI-코딩-판이-바뀌었습니다-클로드코드-에이전트뷰-직접-써봤습니다]]
- **작업 위임**: 서브 에이전트는 처음부터 주 작업을 맡기기보다 보조·검토·특정 페이즈에 투입 [[2026-05-22-클로드-코드-안에서-코덱스를-사용하는-코덱스-플러그인-세팅-가이드]]

## ⚠️ 주의점

서브 에이전트가 많을수록 무조건 좋지 않다. GSD 방식은 계획 단계에만 60만 토큰을 소모해 기본 방식(20만 토큰) 대비 3배를 썼음에도 결과물 품질 차이는 미미했다. **복잡도에 맞게 투입하는 판단**이 핵심이다. [[2026-05-22-GSD-Superpowers-Claude-Code-중-누가-새로운-AI]]

## 한 줄 정의

> **서브 에이전트란, 메인 AI가 특정 작업을 위해 별도로 생성하는 독립 AI로 — 중간 과정을 격리해 메인 컨텍스트를 깨끗하게 유지하면서 동시에 여러 작업을 병렬 처리하게 해주는 분업 구조다.**
