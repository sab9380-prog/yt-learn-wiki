# 웹개발은 끝났다? 웹사이트 통째로 복사하는 미친 오픈소스.. ㄷㄷ

## 🧠 이해 (Understand)
- **Summary:** 웹사이트 주소 하나만 입력하면 해당 사이트를 그대로 복제해주는 오픈소스 'AI Website Cloner Template'을 소개한다. 클로드 코드 기반으로 작동하며, 지도→관찰→코딩→비교 4단계를 거쳐 Next.JS + Tailwind 컴포넌트로 재현한다. 원본 소스코드를 빼오는 게 아니라 화면을 보고 새로 짜는 방식이라 기존 리버스 엔지니어링보다 법적 위험이 낮다. Supabase 홈페이지를 실제 클론한 결과 레이아웃·애니메이션·마우스 이펙트까지 소름 돋을 정도로 재현했다. 단, 피싱·디자인 도용·서비스 약관 위반은 금지이며, 공부·마이그레이션·코드 복구 목적으로 활용하는 것이 바람직하다.
- **Core Message:** 웹사이트 주소 하나로 화면을 보고 그대로 재현하는 AI 클로너를 올바르게 이해하고, 공부·마이그레이션 용도로 윤리적으로 활용하라.
> 웹사이트 주소 하나만 넣으면 그 사이트를 그대로 다시 만들어주는 AI 웹사이트 클로너입니다.
> 화면에 보이는 걸 보고 똑같이 보이게 새로 짜는 방식이기 때문에 겉모습은 비슷해 보여도 원래 코드랑은 완전히 다를 수가 있습니다.
> 그대로 복제해서 내 서비스, 내 웹사이트인 것처럼 올리시면 그건 그냥 짝퉁 사이트고 문제가 생길 수밖에 없어서 이거는 제가 다시 한번 강력하게 말씀을 드리도록 하겠습니다.
❗ AI Website Cloner Template은 2025년 3월 첫 공개 후 4개월 만에 깃허브 스타 3만 7000개를 넘었고, 6월에는 GitHub 트렌딩 TypeScript 부문 1위를 기록했다.
❗ Supabase는 robots.txt에서 GPT봇·클로드봇 등 AI 봇의 접근을 전면 허용하고 있어, 클론 실험에 가장 적합한 사이트였다.
❗ 에이전트가 단순 스크린샷이 아닌 Playwright로 브라우저를 직접 조작하며 마우스 호버 이펙트·탭·메뉴까지 실제로 클릭해 재현한다.

## 📚 핵심 용어
- **AI Website Cloner Template:** URL을 입력하면 해당 사이트 화면을 분석해 Next.JS 코드로 재현해주는 클로드 코드 기반 오픈소스 템플릿. / 건축물 사진을 찍어 도면 없이 똑같이 짓는 것처럼, 소스코드 없이 화면만 보고 사이트를 새로 짓는다. / 기존 리버스 엔지니어링은 앱 내부 코드를 직접 뜯지만, 이 클로너는 눈에 보이는 화면만 보고 새 코드를 짠다. 소스코드 유출 위험이 없다.
- **프록시:** 내 실제 IP 대신 다른 주소를 경유해 웹사이트에 접속하게 해주는 중간 서버. / 대리인에게 심부름을 시키는 것처럼, 내 주소 대신 다른 주소로 사이트에 접속해 IP 차단을 우회한다. / 일반 접속은 내 IP가 그대로 노출되지만, 프록시는 중간 주소가 노출된다. 에이전트 봇 차단(429 에러) 시 우회 수단으로 쓴다.
- **robots.txt:** 웹사이트 운영자가 크롤러·AI 봇의 접근 허용/금지 범위를 명시한 텍스트 파일. / 가게 입구에 붙은 '반려동물 출입 금지' 안내문처럼, 봇에게 어디까지 들어와도 되는지 알려주는 규칙판이다. / 라이선스는 코드 사용 권한을 다루고, robots.txt는 봇의 접근 자체를 허용하는지를 다룬다. 둘 다 확인해야 안전하다.
- **클로드 코드 스킬:** 클로드 코드에서 슬래시 명령어 형태로 저장해 재사용하는 자동화 작업 단위. / 엑셀 매크로처럼, 반복 작업을 명령어 한 줄로 실행할 수 있게 미리 저장해둔 자동화 레시피다. / 일반 프롬프트는 매번 길게 입력해야 하지만, 스킬은 /명령어 하나로 동일한 작업을 즉시 실행한다.
