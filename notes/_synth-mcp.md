# MCP (Model Context Protocol) 종합

## 핵심 정의 — 모든 노트가 동의하는 것

MCP는 **AI가 외부 도구·데이터·서비스에 표준화된 방식으로 접근하게 해주는 연결 규격**이다. USB-C처럼, 기기마다 다른 케이블이 필요했던 것을 하나의 규격으로 통일한 것과 같다. [[2026-07-04-클로드-코드-해커톤2위를-수상한-AI-스타트업의-생존기-이제는-이거]] [[2026-05-22-카카오톡으로-클로드가-들어왔습니다]] [[2026-05-22-카파시도-못-말한-LLM-Wiki의-진실]]
