# MCP (Model Context Protocol) 종합

## 핵심 정의 — 모든 노트가 동의하는 것

MCP는 **AI 모델이 외부 도구·데이터와 표준화된 방식으로 연결되는 공통 규격**이다. 비유는 노트마다 조금씩 다르지만 모두 같은 본질을 가리킨다: USB 표준 [[2026-07-04-클로드-코드-해커톤2위를-수상한-AI-스타트업의-생존기-이제는-이거]], USB-C 충전선 [[2026-05-22-카카오톡으로-클로드가-들어왔습니다]], 비서가 서류함에 직접 접근 [[2026-05-22-카파시도-못-말한-LLM-Wiki의-진실]], 앱스토어 [[2026-05-22-클로드코드채널을-통해-Hermes-Agent를-구독으로만-쓴다고]], [[2026-05-22-한국어더빙-Claude-Design보다-더-나은-도구는-이미-있습니다]]. **하나의 표준으로 모든 도구를 연결**한다는 점이 핵심.
