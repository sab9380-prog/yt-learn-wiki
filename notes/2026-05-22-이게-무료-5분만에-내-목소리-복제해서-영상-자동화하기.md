# 이게 무료? 5분만에 내 목소리 복제해서 영상 자동화하기 | 클로드코드 + 보이스박스 + 하이퍼프레임

## 🧠 이해 (Understand)
- **Summary:** AI 도구를 활용해 한 줄 코딩 없이 영상 제작하는 방법을 소개합니다. VoiceBox로 본인 목소리를 복제해 나레이션을 생성하고, Hyperframe으로 모션 그래픽 영상을 제작합니다. 두 도구 모두 GitHub의 오픈소스이며 무료로 사용 가능합니다. Claude Code의 도움으로 설치부터 영상 완성까지 전 과정을 자동화할 수 있습니다. 음성 복제 시 본인 목소리만 사용해야 하며, 법적 문제를 피해야 합니다.
- **Core Message:** AI 도구와 Claude Code를 활용하면 코딩 없이도 음성부터 영상까지 완전 자동화된 콘텐츠 제작이 가능하다
> 결국 중요한 거는 어떤 영상을 만들고 싶은지를 명확하게 디렉팅하는 감각이 중요한 거 같습니다
> 도구는 점점 쉬워지고 있고 차이는 디렉터의 안목에서 나옵니다
> 음성 복재는 진짜 본인 목소리로만 써 주셔야 합니다
❗ VoiceBox는 GitHub에서 25,000개의 별을 받은 오픈소스 도구
❗ 로컬 음성 복제 도구로 외부 서버로 음성이 전송되지 않음

## 📚 핵심 용어
- **VoiceBox:** GitHub에서 25,000개 별을 받은 로컬 음성 복제 도구 / 녹음실을 컴퓨터 안에 설치하는 것과 같다. 내 목소리 샘플로 무제한 나레이션을 만들 수 있다. / ElevenLabs는 온라인 서비스(비용 발생), VoiceBox는 로컬 설치(무료). 품질은 ElevenLabs가 우수하다.
- **Hyperframe:** AI에게 요청하면 HTML로 모션 그래픽 영상을 생성해주는 도구 / 영상 편집자를 컴퓨터 안에 고용한 것과 같다. 말로만 설명해도 애니메이션 영상을 만들어준다. / 일반 편집 툴은 수동 조작 필요, Hyperframe은 텍스트 명령으로 자동 생성. 실사보다 정보형 영상에 최적화.
- **Claude Code:** 코드 작성과 도구 설치를 자동화해주는 AI 코딩 어시스턴트 / IT 전담 직원을 옆에 두는 것과 같다. 복잡한 설치나 설정을 말로만 지시해도 처리해준다. / 일반 AI는 조언만 제공, Claude Code는 직접 실행까지 담당. 권한 설정으로 자동 실행 가능하다.
