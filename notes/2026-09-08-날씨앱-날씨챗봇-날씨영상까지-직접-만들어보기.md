# 입문자를 위한 API, MCP 완전정복 | 날씨앱 + 날씨챗봇 + 날씨영상까지 직접 만들어보기

## 🧠 이해 (Understand)
- **Summary:** API는 내 앱과 외부 데이터/기능을 이어주는 '웨이터' 역할로, 이를 이해하면 바이브 코딩의 가능성이 폭발적으로 넓어진다. API 키는 서비스 접근 신분증이며 절대 외부에 노출해선 안 된다. MCP는 AI 모델이 외부 도구와 표준화된 방식으로 연결되도록 Anthropic이 2024년 말 제안한 공통 규격이다. 실전으로 무료 날씨 API(Open-Meteo)로 날씨 앱을 만들고, Claude API로 날씨 챗봇을, MCP로 Kling 영상 배경 애니메이션까지 연결하는 과정을 시연했다. 초등·중학생도 API를 이해한 순간 '만들 수 있는 세계'가 무한대로 넓어졌다고 느낄 만큼, API는 바이브 코딩의 핵심 확장 도구다.
- **Core Message:** API·API 키·MCP 개념을 이해하면 바이브 코딩으로 만들 수 있는 세계가 무한대로 넓어진다.
> API는 우리를 새로운 세계로 연결해 주는 문이라고 생각합니다. 내가 만들지 못했고 가지지 못했던 것들이 이 문만 열면 내 프로젝트 안으로 들어올 수 있는 겁니다.
> 아이들이 바이브 코딩에 진짜로 빠져드는 순간이 딱 이 API를 이해했을 때더라고요.
> API 키는 절대 남한테 흘리면 안 됩니다. 남이 내 이름으로 막 주문하고 요금도 폭탄 청구가 나한테 올 수 있는 거잖아요.
❗ MCP는 Anthropic이 2024년 말에 처음 내놓은 표준인데, 현재 OpenAI 등 다른 AI 회사들도 동일한 MCP 규격을 채택해 사용 중이다.
❗ Open-Meteo는 완전 무료 날씨 API로 API 키 없이 전 세계 도시 날씨(최대 16일 예보, 공기질 포함)를 사용할 수 있다.
❗ Kling 모델로 맑음·흐림·안개·비·눈·번개 × 낮/밤 총 12개 날씨 배경 영상을 생성하는 비용이 약 6달러(약 8,000원) 수준이다.

## 📚 핵심 용어
- **API:** 내 앱이 외부의 데이터나 기능을 가져다 쓸 수 있도록 연결해 주는 통신 규칙. / 식당 웨이터처럼, 주방(외부 데이터)에 직접 들어가지 않아도 메뉴만 주문하면 결과를 가져다 준다. / API는 '연결 규칙' 자체고, API 키는 그 연결을 허용받는 '신분증'이다. 규칙과 자격증은 다르다.
- **API 키:** API를 사용할 자격이 있는지 확인하고 사용량을 추적하는 개인 식별 코드. / 회원제 식당의 멤버십 카드. 잃어버리면 남이 내 이름으로 주문하고 요금이 나한테 온다. / API는 식당 시스템 전체고, API 키는 내 입장권이다. 키 없이는 API를 호출해도 거부된다.
- **MCP:** AI 모델이 외부 도구·데이터와 연결될 때 쓰는 표준화된 공통 규격(Anthropic이 2024년 말 제안). / 해외여행 때 나라마다 콘센트 모양이 달라 어댑터가 필요하듯, MCP는 AI와 외부 도구를 하나의 규격으로 통일한 만능 어댑터다. / API는 데이터를 주고받는 연결 통로고, MCP는 AI가 여러 API·도구에 꽂힐 수 있는 표준 플러그 규격이다.
- **환경 변수:** API 키 같은 민감 정보를 코드 밖 별도 파일(.env)에 숨겨 관리하는 방식. / 금고에 열쇠를 따로 보관하듯, 소스코드에 직접 쓰지 않고 별도 파일에 잠가 두는 것. / 코드에 직접 키를 쓰면 GitHub 업로드 시 전 세계에 노출되지만, 환경 변수 파일(.env)은 .gitignore로 업로드가 차단된다.
