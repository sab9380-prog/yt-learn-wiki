# 현직 9년차 메타 AX 엔지니어가 경고하는 "진짜 AX"

## 🧠 이해 (Understand)
- **Summary:** Meta 9년 차 개발자이자 Agent Transformation 팀 테크 리드인 Alex가 AX(에이전트 중심 워크플로우 전환)의 본질을 정의하고 실전 경험을 Q&A 형식으로 정리한 영상이다. AX는 AI 도구 도입이 아니라, 인간 중심 업무 구조를 에이전트 중심으로 체계적으로 재설계하는 것이다. 성공 지표는 토큰 사용량이 아닌 동일 인력·자원으로 얼마나 많은 비즈니스 가치를 창출했는지이며, 평가(온라인·오프라인), 거버넌스, 보안, 하네스 엔지니어링이 AX의 핵심 구성 요소다. 리더십 주도의 문화·프로세스 변화 없이는 AX가 실패하며, AX 커리어는 비즈니스·운영·프로세스 최적화 역량을 기르는 본질적인 길이다. 궁극적 목표는 AI가 95%를 결정하고 인간이 5%에만 개입하는 'Human-in-the-loop' 조직이다.
- **Core Message:** AX는 AI 도구 도입이 아니라 인간 중심 업무 구조를 에이전트 중심으로 체계적으로 재설계하는 것이며, 그 성패는 기술보다 비즈니스 임팩트 측정과 리더십 주도 문화 변화에 달려 있다.

## 📚 핵심 용어
- **AX (에이전트 전환):** 인간 중심 업무·조직·워크플로우를 에이전트 중심으로 체계적으로 재설계하는 전환 작업. / 공장 라인을 수작업에서 자동화 로봇 라인으로 전면 재설계하는 것과 같다. 단순히 로봇 한 대 들여오는 게 아니라, 공정 전체를 다시 짠다. / AI 도입(AI Adoption)은 도구를 추가하는 것, AX는 도구에 맞게 조직 구조 자체를 바꾸는 것. 범위와 깊이가 다르다.
- **하네스:** 회사 내부 API·시스템과 AI 모델을 연결하고 제어하는 조직 고유의 에이전트 실행 틀(툴킷). / 말을 제어하는 마구(馬具)처럼, AI 모델이라는 힘을 회사 업무 방향으로 안전하게 이끄는 장치다. / Claude Code·Codex는 범용 도구, 하네스는 그 위에 얹어 사내 시스템과 연결·제어하는 맞춤 레이어. 외부 도구는 내부 API 통제가 불가하다.
- **온라인·오프라인 평가:** 실사용자 행동 데이터로 측정하는 온라인 평가와, 사전 시나리오 데이터셋으로 실행하는 오프라인 평가 두 가지 에이전트 품질 검증 방식. / 온라인 평가는 실제 손님 반응으로 메뉴를 평가하는 것, 오프라인 평가는 출시 전 내부 시식 테스트. 둘 다 해야 한다. / 온라인은 실제 사용 궤적 기반(현실 반영), 오프라인은 예상 질문 기반(통제된 환경). 모델 업데이트 전 검증은 반드시 오프라인 먼저다.
- **Human-in-the-loop:** AI 에이전트가 대부분의 결정을 처리하고, 인간은 꼭 필요한 순간에만 개입하는 자동화 조직 구조. / 비행기 자동조종 장치가 95%를 운항하고, 조종사는 이착륙 같은 결정적 순간에만 개입하는 것과 같다. / Human-out-of-the-loop는 인간이 전혀 개입 안 하는 완전 자동화, Human-in-the-loop는 인간이 선택적으로만 개입. 현실적 목표는 후자다.
