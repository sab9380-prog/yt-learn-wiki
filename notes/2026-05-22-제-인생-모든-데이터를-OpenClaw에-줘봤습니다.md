- **Core Message:** 모든 일상 데이터를 체계적으로 기록하고 AI와 연결하면, 나의 과거를 요약하고 현재를 최적화하며 미래를 계획하는 개인화된 생산성 시스템을 만들 수 있다.

## 📚 핵심 용어
- **라이프로깅:** 일상생활의 모든 활동과 경험을 디지털 기기로 지속적으로 기록하는 것 / 개인 비서가 24시간 내 모든 행동을 메모하는 것과 같다. 언제 어디서 무엇을 했는지 빠짐없이 기록해둔다. / 일반 일기는 주관적 감정 위주지만, 라이프로깅은 객관적 데이터(시간, 위치, 활동)까지 포함한 전면적 기록이다.
- **DIKW 피라미드:** 데이터→정보→지식→지혜로 발전하는 단계적 가치 창출 프레임워크 / 원석을 캐서 보석으로 만드는 과정과 같다. 데이터라는 원석에서 패턴을 찾고, 의미를 부여해 행동 가능한 지혜를 만든다. / 단순 데이터 수집은 창고에 물건만 쌓는 것이고, DIKW는 그 물건들로 실용적인 가구를 만드는 과정이다.
- **Personal Context Management:** 나와 관련된 개인 데이터를 AI에게 제공해 맞춤형 조언을 받는 방식 / 가정의학과 주치의가 내 병력과 생활습관을 다 알고 있어서 정확한 처방을 내리는 것처럼, AI가 내 맥락을 알고 조언한다. / 일반 AI 질문은 구글 검색 같지만, PCM은 나를 잘 아는 친구에게 상담받는 것과 같다.
- **Agent Harness:** AI를 안전하고 효과적으로 제어하기 위한 환경과 도구 체계 / 야생마를 타려면 고삐와 안장이 필요하듯, AI라는 강력한 도구를 내가 원하는 방향으로 이끌기 위한 장비다. / ChatGPT 단순 대화는 말 등에 그냥 올라타는 것이고, Agent Harness는 승마 장비를 완비한 상태다.
