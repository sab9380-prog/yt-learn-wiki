# agent.md 종합 노트

## 한 문장으로 먼저

**agent.md(또는 CLAUDE.md)는 AI에게 매번 설명하는 대신, "항상 이 규칙으로 일해"를 파일 하나에 박아두는 영구 지침서다.**

---

## 핵심: 모든 노트가 동의하는 것

> **AI가 매번 잘못 판단하는 이유는 능력 부족이 아니라 맥락 부족이다.**

agent.md는 프로젝트 루트(또는 홈 디렉토리)에 두는 마크다운 파일로, AI가 작업할 때마다 **자동으로** 참조하는 사전 규칙집이다. 신입 직원 매뉴얼처럼, 한 번 써두면 매 대화에서 다시 말할 필요가 없다. [[2026-06-29-바이브코딩계-GD가-공유한-CLAUDE-md-나눕니다]] [[2026-06-25-왜-스킬이-졌을까-feat-agent-md-의-비밀]] [[2026-05-22-ChatGPT만-쓰면-손해입니다-Codex-쓰세요-초보자-튜토리얼]]

---

## 서로 다른 관점·강조

### 1. "무엇을 막을 것인가" — AI 고질병 차단 도구로서의 관점
AI 코딩의 3대 고질병(잘못된 가정 / 코드 부풀리기 / 멋대로 고치기)을 막기 위해 4원칙을 파일화:
- 작업 전 먼저 질문하기
- 최소 코드만 쓰기
- 요청한 부분만 외과적으로 수정하기
- 명령 대신 성공 기준 제시하기

카파시의 분석을 65줄로 정리한 파일이 깃헙 스타 10만 개, 1주일에 43,000명이 설치했다는 사실이 이 수요를 증명한다. [[2026-06-29-바이브코딩계-GD가-공유한-CLAUDE-md-나눕니다]] [[2026-05-22-The-Karpathy-CLAUDE-md-File-That-43-000]]

### 2. "선택을 없애라" — 정확도의 원리로서의 관점
Vercel 실험에서 Skills(AI가 알아서 꺼내는 방식)는 79점, agent.md는 100점. Skills를 줘도 AI가 10번 중 6번 꺼내 보지 않았고, 아무것도 안 준 것(53점)과 같은 결과가 나왔다. **"선택을 시키면 틀려요. 선택을 안 시키면 안 틀려요."** 단, 문서를 80% 압축(목차만 남겨도)해도 100점이 유지됐다. [[2026-06-25-왜-스킬이-졌을까-feat-agent-md-의-비밀]]

### 3. "무엇을 담을 것인가" — 활용 목적별 내용
노트들은 담기는 내용에 따라 여러 파일명·역할로 분화한다:
- **디자인 규칙** → design.md (색상 3개, 여백 단위, 그라데이션 금지 등 — 금지 10줄만으로 제품이 달라 보임) [[2026-07-12-4일-만에-만들었는데-결제-붙이는-데-2달-걸렸습니다]] [[2026-05-22-AI-티-나는-PPT-10분-만에-싹-바꾸는-법]] [[2026-05-22-디자인-프로세스-없애버린-클로드-디자인-19분-만에-끝내기]]
- **프로젝트 행동 원칙** → agent.md / CLAUDE.md (목표, 제약, 금지 행동) [[2026-05-22-ChatGPT만-쓰면-손해입니다-Codex-쓰세요-초보자-튜토리얼]]
- **조직 가이드** → 팀 규칙, 코딩 컨벤션, 부서별 매뉴얼 [[2026-05-22-Anthropic이-직접-공개한-5가지-비밀-모델보다-이게-더-중요합니다]]

## 실전 적용

| 상황 | 방법 |
|------|------|
| AI 디자인이 매번 달라 보임 | design.md에 금지 항목 10줄 작성 |
| AI가 너무 많은 코드를 짬 | CLAUDE.md에 최소 코드 원칙 삽입 |
| AI가 요청 안 한 부분까지 고침 | "요청된 줄만 수정" 규칙 추가 |
| 맥락이 길어 파일이 무거움 | 목차만 남겨 80% 압축해도 효과 동일 |
| 모든 프로젝트에 자동 적용 원함 | `~/.claude/CLAUDE.md` 홈 디렉토리에 글로벌 저장 |

## 주의점·상충

- **agent.md 만능은 아님**: 특수하고 대형인 작업(예: 수백 페이지 문서 처리)은 Skills를 수동 호출하는 조합이 최적 [[2026-06-25-왜-스킬이-졌을까-feat-agent-md-의-비밀]]
- **파일만 있으면 되는 게 아님**: 맨 위에 "외운 지식 말고 이 문서를 먼저 봐"라는 한 줄을 넣어야 AI가 실제로 참조한다 — 이 한 마디가 100점과 53점을 가른다 [[2026-06-25-왜-스킬이-졌을까-feat-agent-md-의-비밀]]
- **비용**: 클로드 디자인에서 테스트만으로 47달러가 발생한 사례처럼, 강력한 도구일수록 비용 모니터링 필요 [[2026-05-22-디자인-프로세스-없애버린-클로드-디자인-19분-만에-끝내기]]

## 한 줄 정의

**agent.md란, AI에게 매번 설명하는 수고를 없애고 항상 같은 기준으로 일하게 만드는 "영구 업무 매뉴얼" 파일이다.**
