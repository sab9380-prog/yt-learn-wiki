# 소프트웨어는 끝났다? 앱 통째로 복사하는 미친 오픈소스.. ㄷㄷ

## 🧠 이해 (Understand)
- **Summary:** Reverse Engineer Anything(REA)은 기존 앱을 AI 에이전트가 자동 분석해 유사 앱을 재현하도록 돕는 오픈소스 MCP 도구다. NSA 출신 Ghidra 등 검증된 바이너리 분석 툴들을 에이전트가 쓰기 쉽게 하나로 묶은 것이 핵심으로, 새로운 기술이 아니라 기존 기술의 접근성 혁신이다. 실제로 윈도우 그림판을 11분 만에 리버스 엔지니어링해 커스텀 기능까지 추가하는 데 성공했다. 상업 앱 무단 복제는 불법이므로, 개인 학습·오픈소스 앱·자신의 앱 기능 확장 용도가 적합한 활용법이다. 이 흐름은 소프트웨어 대중화를 가속하며, 기업들은 핵심 로직을 앱 내장 대신 서버 기반으로 전환하는 방향으로 대응할 것으로 예상된다.
- **Core Message:** REA는 새로운 기술이 아니라 기존 분석 툴의 접근성 혁신으로, 코딩 비전문가도 앱을 뜯어 자신만의 기능을 붙일 수 있는 시대가 열렸다.
> 이미 있는 아이디어를 섞는 문턱이 확 낮아졌습니다.
> 아무런 지식도 없이 처음부터 끝까지 해줘, 안 되는데? 요것만 하시면 AI를 사용한다고 말하기 조금 부끄러울 수 있습니다.
> 대부분의 소프트웨어가 사실상 오픈소스처럼 될 겁니다.
❗ Ghidra는 NSA(미국 국가안보국)가 20년 가까이 내부에서만 쓰다가 2017년 위키리크스 폭로로 존재가 알려진 뒤 2019년에야 오픈소스로 공개됐다.
❗ REA로 윈도우 그림판을 분석하고 커스텀 기능까지 추가하는 데 걸린 시간이 단 11분이었다.
❗ REA 깃허브 스타가 공개 직후 15만 개를 돌파했으며, Replit CEO가 '이건 미쳤다'고 반응할 정도로 업계 충격을 줬다.

## 📚 핵심 용어
- **Reverse Engineer Anything (REA):** 기존 앱을 자동 분석해 AI 에이전트가 동일 기능을 재현하도록 지시하는 오픈소스 MCP 도구. / 완성된 요리를 먹어보고 레시피를 역추적하는 것처럼, 만들어진 앱을 뜯어 설계도를 복원한다. / 일반 바이브 코딩은 처음부터 직접 설계하지만, REA는 이미 존재하는 앱의 동작 원리를 먼저 파악한 뒤 짓는다.
- **MCP:** AI 에이전트가 외부 도구·서비스를 호출할 수 있도록 연결해주는 표준 인터페이스 규격. / 스마트폰 앱 스토어처럼, 에이전트가 필요한 도구를 골라 꽂아 쓸 수 있게 해주는 연결 소켓이다. / API는 개발자가 직접 호출 코드를 짜야 하지만, MCP는 에이전트가 알아서 도구를 선택·호출한다.
- **Ghidra:** NSA가 약 20년간 내부용으로 개발하다 2019년 오픈소스로 공개한 바이너리 역분석 툴. / 암호화된 문서를 해독하는 정보기관 전용 사전이 일반에 공개된 것과 같다. / IDA·Hopper도 같은 역할이지만, Ghidra는 무료 오픈소스이고 정보기관 검증 이력이 있다는 점이 다르다.
- **Pseudo 코드:** 앱의 동작 흐름을 실제 코드 문법 없이 사람이 읽을 수 있는 자연어 형태로 정리한 설계 문서. / 건축 청사진처럼, 벽돌 쌓는 법 대신 '여기에 문, 저기에 창문'이라고 적어 놓은 것이다. / 실제 코드는 기계가 실행하는 명령이지만, Pseudo 코드는 인간이 의도를 파악하기 위한 초안이다.
