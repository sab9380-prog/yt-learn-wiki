- **Core Message:** AI가 코딩을 도와주더라도 개발자는 전체 개발 생태계와 배포 과정을 이해해야 진정한 개발이 가능하다.

> 서버 프로그램을 뛸 때는 이런 포트와 함께 뜬다라고 이해하시면 됩니다.
> 전반적으로 AI를 개발하더라도 어느 정도 좀 알아야 될 부분들이 곳곳에 있어서
❗ AI 코딩 도구를 사용해도 여전히 많은 IT 기초 지식이 필요하다

## 📚 핵심 용어
- **IDE (통합 개발 환경):** 코드 작성, 실행, 디버깅을 한 곳에서 할 수 있는 프로그램. / 워드프로세서처럼 글쓰기의 모든 기능을 제공하듯, 개발의 모든 작업을 한 프로그램에서 처리할 수 있다. / 메모장은 단순 텍스트 편집만 가능하지만, IDE는 편집부터 실행까지 모든 개발 기능을 제공한다.
- **API (Application Programming Interface):** 앱과 서버가 데이터를 주고받기 위한 규칙과 형식. / 식당 메뉴판과 같다. 고객이 메뉴를 보고 주문하면 주방에서 음식을 제공하듯, 정해진 형식으로 요청하면 데이터를 받는다. / 웹페이지는 사람이 보는 화면이지만, API는 프로그램끼리 소통하는 데이터 전용 창구다.
- **포트 (Port):** 서버에서 각 프로그램을 구분하는 번호. / 아파트 동호수와 같다. 같은 건물(서버)에 여러 집(프로그램)이 있을 때 정확한 집을 찾아가는 주소 번호다. / IP 주소가 건물을 찾는 주소라면, 포트는 그 건물 안의 구체적인 호수를 가리킨다.
- **배포 (Deploy):** 개발한 프로그램을 실제 서버에 올려서 사용자가 접근할 수 있게 하는 과정. / 책을 출간하는 것과 같다. 원고를 완성했다고 끝이 아니라 인쇄소에서 책으로 만들어 서점에 진열해야 독자가 볼 수 있다. / 로컬 테스트는 내 컴퓨터에서만 실행되지만, 배포는 전 세계 누구나 접속할 수 있게 공개하는 것이다.
