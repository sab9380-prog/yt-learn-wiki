# AI 코딩 판이 바뀌었습니다. 클로드코드 에이전트뷰 직접 써봤습니다 \#클로드코드 \#agents

## 🧠 이해 (Understand)
- **Summary:** Anthropic의 Claude Code에 새로 추가된 Agent View 기능을 소개하는 영상입니다. Agent View는 여러 Claude 세션을 한 화면에서 관리할 수 있는 대시보드로, 개발자들이 터미널 탭을 여러 개 띄워가며 작업하던 기존 방식의 문제점을 해결합니다. 이 기능은 각 세션을 자동으로 격리된 작업공간에 배치하여 충돌을 방지하고, 15초마다 세션 상태를 자동 업데이트하며, peek 기능으로 세션에 직접 들어가지 않고도 미리보기와 응답이 가능합니다. 특히 '퇴근점 파견 패턴'이라는 새로운 작업 방식을 제안하는데, 퇴근 전에 여러 작업을 백그라운드로 실행시키고 다음날 결과를 확인하는 방식입니다. 다만 여러 세션 동시 사용으로 인한 토큰 소비 급증이라는 단점도 존재합니다.
- **Core Message:** Claude Code의 Agent View는 개발자의 작업 방식을 한 줄씩 직접 코딩하는 동기 방식에서 여러 에이전트가 동시에 작업하는 비동기 방식으로 근본적으로 변화시키고 있다.
> 진짜 코딩이 끝났습니다. 냉정하게 말씀드릴게요. 지금이 순간에도 누군가는 자고 있어요. 그동안 에이전트 다섯 개가 동시에 코드를 짜고 있습니다.
> 개발자는 에이전트를 밤새 돌려야 된다. 잠자는 시간이 곧 코딩 시간이 되는 겁니다.
> 한 줄씩 직접 코딩하는 시대는 이제 끝났다는 얘기예요.
❗ Agent View는 2024년 5월 11일에 조용히 발표되었지만 개발 방식을 근본적으로 바꾸고 있다
❗ 4개~8개 세션 동시 운영이 황금 비율이며, 그 이상은 관리 비용이 작업 이득을 잡아먹는다
❗ 복잡한 작업 하나에 5만~15만 토큰을 소비하므로 4개 세션 동시 실행 시 한 시간 만에 프로 플랜 한도를 소진할 수 있다

## 📚 핵심 용어
- **Agent View:** 모든 Claude Code 세션을 한 화면에서 관리하고 모니터링할 수 있는 대시보드 / 여러 직원이 일하는 사무실을 한 눈에 볼 수 있는 관리자 모니터와 같다. 누가 뭘 하는지, 진행상황은 어떤지 실시간으로 파악 가능하다. / 기존 터미널 탭 관리와 달리, Agent View는 모든 세션 상태를 자동으로 요약하고 분류해서 보여준다. 일일이 탭을 클릭할 필요가 없다.
- **비동기 코딩:** 개발자가 직접 한 줄씩 코드를 작성하지 않고, 여러 AI 에이전트가 동시에 작업하는 개발 방식 / 요리사가 모든 요리를 직접 하지 않고 여러 보조 요리사에게 동시에 일을 맡기는 것과 같다. 메인 요리사는 지시와 관리만 한다. / 기존 동기 코딩은 개발자가 직접 모든 코드를 작성하지만, 비동기 코딩은 AI가 대부분을 작성하고 개발자는 관리와 검토에 집중한다.
- **워크트리 자동 격리:** 각 Claude 세션을 독립된 작업공간에 배치하여 동시 작업 시 충돌을 방지하는 기능 / 아파트의 각 세대가 독립된 공간을 가지는 것처럼, 각 에이전트가 같은 코드를 보지만 작업하는 공간은 분리되어 있다. / 일반적인 멀티태스킹은 같은 파일을 여러 곳에서 수정해 충돌이 발생하지만, 워크트리 격리는 각각 독립된 복사본에서 작업한다.
- **퇴근점 파견 패턴:** 퇴근 전에 여러 작업을 백그라운드 에이전트에게 맡기고, 다음날 아침 결과를 확인하는 작업 방식 / 야간 경비원에게 건물 점검을 맡기고 다음날 아침 보고서를 받는 것과 같다. 잠자는 시간에도 일이 진행된다. / 일반적인 개발은 개발자가 직접 작업하는 시간에만 진행되지만, 이 패턴은 24시간 연속으로 작업이 가능하다.
