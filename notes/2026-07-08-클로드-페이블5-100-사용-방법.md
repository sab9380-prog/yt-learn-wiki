## 🧠 이해 (Understand)
- **Summary:** 미국 정부가 공개를 막았을 만큼 성능이 뛰어난 Claude Fable 5(영상에서 '페이블 5'로 지칭)를 제대로 활용하려면 Anthropic 공식 프롬프트 작성 가이드를 따라야 한다. 가이드 페이지 링크를 Claude에게 던져 '내가 만들 프로그램에 맞는 프롬프트를 만들어 달라'고 하면 최적화된 프롬프트를 자동 생성해 준다. 이 방법으로 Claude Code에서 캡컷 유사 자막 편집 프로그램을 단 한 번의 프롬프트로 완성했다. 완성된 프로그램은 자동 자막 생성, 폰트/위치/배경 스타일 편집, 영상 내보내기까지 지원한다. 핵심은 목적을 명확히 전달하면 Claude 5가 스스로 판단·피드백하며 최적 결과를 낸다는 것이다.
- **Core Message:** Anthropic 공식 프롬프트 가이드를 Claude 자신에게 읽혀 최적 프롬프트를 만들게 하면, Claude Code로 복잡한 프로그램도 단번에 완성할 수 있다.
> 목적을 이야기해 주면 페이블 5가 스스로 판단하고 스스로 피드백하면서 최적의 결과를 낸다.
> 그 페이지의 내용을 그대로 클로드에게 던져 주고 내가 원하는 작업을 만들어 달라고 하면 페이블 5가 효과적으로 작동할 수 있도록 프롬프트를 만들어 줍니다.
❗ 성능이 너무 뛰어나서 미국 정부가 한때 공개를 막았다고 언급될 만큼 Claude Fable 5의 성능이 주목받고 있다.
❗ Anthropic 공식 홈페이지에 Claude 5 전용 프롬프트 작성법 가이드가 별도 페이지로 공개되어 있다.
❗ Claude Code 한 번의 프롬프트 실행으로 자동 자막 생성·스타일 편집·영상 내보내기를 갖춘 캡컷 유사 프로그램이 완성됐다.

## 📚 핵심 용어
- **클로드 코드 (Claude Code):** Claude AI가 직접 코드를 작성·실행·수정하며 프로그램을 완성해 주는 개발 도구. / 내가 '이런 가구 만들어줘'라고 말하면 목수가 설계부터 조립까지 혼자 다 해주는 것과 같다. / 일반 Claude 채팅은 코드를 '알려주는' 것이고, Claude Code는 실제 파일을 만들고 실행까지 '해주는' 것이다.
- **시스템 프롬프트:** AI가 작업 전에 읽고 따르도록 미리 설정해 두는 역할·규칙 지침서. / 직원에게 업무 매뉴얼을 미리 읽혀 두는 것처럼, AI에게 '이런 방식으로 일해'를 사전에 알려주는 문서다. / 일반 질문(프롬프트)은 그때그때 지시인 반면, 시스템 프롬프트는 대화 내내 유지되는 기본 규칙이다.
- **목적 기반 프롬프팅:** 세부 방법을 지시하지 않고 '최종 목적'만 명확히 전달해 AI가 스스로 최적 방법을 찾게 하는 방식. / 'A에서 B로 가장 빠르게 데려다줘'라고만 해도 택시 기사가 알아서 최적 경로를 찾는 것과 같다. / 단계별 지시 프롬프팅은 방법을 인간이 설계하지만, 목적 기반은 AI가 스스로 판단·피드백하며 결과를 낸다.
- **클로드 스킬:** Claude Code가 반복 작업에 활용하는 사전 정의된 도구·기능 모음. / 요리사가 자주 쓰는 칼·도마·계량컵을 미리 꺼내 두고 요리를 시작하는 것과 같다. / MCP가 외부 서비스 연결 도구라면, 클로드 스킬은 Claude Code 내부에서 재사용 가능한 작업 템플릿이다.
