# 코덱스 (Codex) 종합 노트

## 핵심 정의
**코덱스(Codex)는 OpenAI가 만든 프로젝트 폴더 기반 AI 코딩/업무 에이전트**로, ChatGPT 구독으로 사용 가능하다. 단순 질답이 아니라 리서치→계획→구현→검수까지 전체 업무 프로세스를 자율 실행한다. [[2026-05-22-ChatGPT만-쓰면-손해입니다-Codex-쓰세요-초보자-튜토리얼]]

---

## 노트들이 공통으로 말하는 것
- **코드 생성보다 검증이 핵심**: 코덱스가 만들어주는 결과물 자체보다, 검증 프로세스와 하네스 설계가 퀄리티를 결정한다 [[2026-06-29-클로드-코드와-코덱스-업데이트-빠르게-살펴보기]]
- **작업 표면의 확장**: CLI → 브라우저 → 슬랙 → 컴퓨터 직접 조작(컴퓨터 유즈) → 레코드&리플레이까지 자동화 범위가 계속 넓어지고 있다 [[2026-06-29-클로드-코드와-코덱스-업데이트-빠르게-살펴보기]] [[2026-05-22-ChatGPT만-쓰면-손해입니다-Codex-쓰세요-초보자-튜토리얼]]

## 서로 다른 강조점

|---|---|---|

| 클로드 코드와 비교 | 단일 모델 의존은 위험 — 코덱스와 클로드를 상호 검증용으로 병행 사용 | [[2026-05-22-클로드-코드-하나만-쓰면-이제-망합니다-feat-Codex]] |
| 워크플로우 구조 | 다이나믹 워크플로우(딥리서치·울트라코드)로 작업을 단계별 페이즈로 동적 분할 | [[2026-06-04-클로드-코드-Dynamic-Workflow-기능-비교-총정리]] |
| 자동화 속도 | 검증 가능한 업무부터 AI가 먼저 대체 — 코드 생성 가치는 0에 수렴 | [[2026-06-29-클로드-코드와-코덱스-업데이트-빠르게-살펴보기]] |

## 실전 적용 방법

**입문자라면 이 순서로:**
1. **환경 세팅**: 프로젝트 폴더 생성 + `agent.md`(업무 지침서) 작성 [[2026-05-22-ChatGPT만-쓰면-손해입니다-Codex-쓰세요-초보자-튜토리얼]]
2. **역할 분담**: 오프스(설계) → 코덱스 adversarial review(비판 검토) → 구현 → 코덱스 재검수 — 비용이 1/3로 절감 [[2026-05-22-클로드-코드-하나만-쓰면-이제-망합니다-feat-Codex]]
3. **검증 하네스 설계**: 내 도메인에 맞는 검증 기준을 문서화 — 하네스 없이 연속 작업 성공률은 34%로 급락, 잘 설계하면 70~80% 유지 [[2026-06-29-클로드-코드와-코덱스-업데이트-빠르게-살펴보기]]
4. **레코드&리플레이 활용**: 반복 수작업을 녹화해 코덱스 스킬로 변환 — 코드 없이 자동화 가능 [[2026-06-29-클로드-코드와-코덱스-업데이트-빠르게-살펴보기]]

---

## 주의점·상충

- **단일 모델 의존 금지**: 같은 회사 모델끼리는 같은 곳에서 실수한다. 클로드+코덱스 병행이 더 안전하다 [[2026-05-22-클로드-코드-하나만-쓰면-이제-망합니다-feat-Codex]]
- **발전 속도가 분석 속도를 앞지름**: 레코드&리플레이는 발표 준비 중에 실제 출시될 만큼 변화가 빠르다 — 지금 배운 것도 금방 달라진다 [[2026-06-29-클로드-코드와-코덱스-업데이트-빠르게-살펴보기]]
- **프롬프트 길이보다 구조**: 긴 프롬프트 하나보다 `agent.md` 같은 기준 문서 체계가 안정적 결과를 만든다 [[2026-05-22-ChatGPT만-쓰면-손해입니다-Codex-쓰세요-초보자-튜토리얼]]

---

## 한 줄 정의
코덱스는 OpenAI의 프로젝트 폴더 기반 AI 업무 에이전트로, 잘 쓰려면 결과 생성보다 **검증 구조(하네스) 설계**가 핵심이다.
