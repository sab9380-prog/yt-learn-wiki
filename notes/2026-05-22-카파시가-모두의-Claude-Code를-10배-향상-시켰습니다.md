# 카파시가 모두의 Claude Code를 10배 향상 시켰습니다...

## 🧠 이해 (Understand)
- **Summary:** 이 영상은 안드레이 카파시가 개발한 LLM 위키 시스템을 클로드 코드와 옵시디언을 사용해 구축하는 방법을 설명합니다. 기존 RAG 방식과 달리 마크다운 파일 기반으로 문서들을 관계형으로 연결하여 개인 지식 베이스를 만드는 방식입니다. raw 폴더에 원본 자료를 넣으면 클로드가 자동으로 분석하여 wiki 폴더에 체계적으로 정리하고 연결합니다. 옵시디언 웹클리퍼로 쉽게 자료를 수집하고, 클로드 코워크로 반복 작업을 자동화하여 지속적으로 지식이 축적되는 시스템을 구축할 수 있습니다.
- **Core Message:** 복잡한 RAG 기술 없이도 마크다운 파일과 AI만으로 지속적으로 성장하는 개인 지식 베이스를 만들 수 있다.
> 나는 비싼 RAG 기술을 써야 할 줄 알았는데 그냥 마크다운 폴더만으로도 충분했다
> 지식이 은행처럼 계속해서 복리처럼 쌓이는 거거든요
> AI가 모든 걸 기억하고 정리해 주는 지치지 않는 개인 비서 같은 느낌
❗ 383개 흩어진 파일과 100개 미팅 녹음을 정리했더니 토큰 사용량이 95% 줄었다
❗ 네이트 허크는 36개 영상 자막을 14분만에 연결하는 지식 시스템을 만들었다
❗ 안드레이 카파시의 한 줄 트윗이 며칠 만에 바이럴되어 새로운 지식 관리 트렌드를 만들었다

## 📚 핵심 용어
- **LLM 위키:** AI가 문서들을 자동 분석하여 관계형으로 연결한 개인 지식 베이스 / 도서관의 카드 목록 같다. 책마다 관련 주제와 참조 문헌이 연결되어 있어 필요한 지식을 쉽게 찾을 수 있다. / RAG는 검색어와 비슷한 내용을 찾는 것, 위키는 문서 간 관계를 따라가는 것. 위키가 맥락 이해에 더 유리하다.
- **백링크:** 한 문서에서 다른 문서를 참조하는 연결고리 / 위키피디아의 파란 링크와 같다. 클릭하면 관련 문서로 이동하며 지식의 연결고리를 탐색할 수 있다. / 일반 검색은 키워드로 찾는 것, 백링크는 개념 간 관계로 찾는 것. 백링크가 더 체계적인 지식 탐색을 가능하게 한다.
- **린팅:** 위키 시스템의 깨진 링크나 잘못된 연결을 점검하고 수정하는 작업 / 자동차 정기점검과 같다. 주기적으로 시스템을 검사해 문제를 찾고 고쳐서 최적 상태를 유지한다. / 일반 파일 정리는 수동으로 하는 것, 린팅은 AI가 자동으로 하는 것. 린팅이 훨씬 효율적이다.
