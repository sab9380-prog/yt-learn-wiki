# 디자인 프로세스 없애버린 클로드 디자인 19분 만에 끝내기

[[_category-일반학습]]

## 🧠 이해 (Understand)
- **Summary:** 엔트로픽의 클로드 디자인 출시로 기존 디자인 프로세스의 패러다임이 변화하고 있다. 피그마 전 디자인 디렉터가 기존의 발산-수렴 중심 디자인 프로세스가 끝났다고 선언했고, 클로드 디자인은 AI를 통해 빠른 프로토타이핑과 즉시 검증을 가능하게 한다. 클로드 디자인의 핵심 기능은 디자인 시스템을 쉽게 구축하고 이를 바탕으로 슬라이드, 웹 앱, 프로토타입을 생성하는 것이다. 디자인 MD 파일이나 피그마 파일을 업로드하면 자동으로 디자인 시스템을 생성하며, WebGL 쉐이더, 3D 렌더링, 애니메이션 등 고급 효과도 구현할 수 있다. 트윅스 기능으로 실시간 수정이 가능하고, 드로잉 기능으로 섬세한 조정도 할 수 있다. 다만 비용이 상당히 발생한다는 단점이 있다.
- **Core Message:** 클로드 디자인은 디자인 시스템 기반으로 AI가 빠르게 프로토타입을 생성하고 검증할 수 있게 하여 기존의 느린 디자인 프로세스를 혁신한다.
> 기존의 디자인 프로세스는 끝났다 - 피그마 전 디자인 디렉터
> 엔지니어들이 일곱 개의 클로드를 동시에 돌리며 코드를 찍어내는 지금의 AI 시대
> 이제 디자인 시스템 하나만 구축해 두면 그것들을 조합해서 디자인을 만들어 주는 것까지 AI에게 위임할 수 있다
❗ 클로드 디자인 출시 소식에 피그마 주가가 7% 하락했다
❗ 테스트 과정에서만 47달러의 비용이 발생했다
❗ 피그마 커뮤니티의 기업 디자인 시스템 파일을 바로 업로드해서 사용할 수 있다

## 📚 핵심 용어
- **디자인 시스템:** 브랜드 컬러, 폰트, 컴포넌트 등 디자인 규칙을 통일한 가이드라인 집합 / 레시피북처럼 요리사가 일관된 맛을 내기 위해 따라야 할 재료와 방법이 정리된 것 / 디자인 가이드는 참고 문서, 디자인 시스템은 실제 사용할 컴포넌트와 코드까지 포함한 실행 도구
- **디자인 MD 파일:** 디자인 시스템을 마크다운 형식으로 문서화한 파일 / 건축 도면처럼 건물을 짓기 위한 모든 규칙과 스펙을 글로 정리해둔 설계서 / 피그마 파일은 시각적 컴포넌트 중심, MD 파일은 텍스트로 규칙을 명시하여 AI가 이해하기 쉬움
- **WebGL 쉐이더:** 웹브라우저에서 GPU를 활용해 실시간 그래픽 효과를 만드는 프로그램 / 포토샵 필터처럼 이미지에 빛, 그림자, 왜곡 효과를 실시간으로 적용하는 마법사 / CSS 애니메이션은 미리 정해진 움직임, 쉐이더는 실시간으로 계산되는 복잡한 시각 효과
- **트윅스 기능:** 슬라이더나 옵션으로 디자인 요소를 실시간으로 조정할 수 있는 도구 / 음향 믹서처럼 각 채널의 볼륨과 효과를 다이얼로 돌려가며 실시간으로 조절하는 것 / 코드 수정은 전문 지식 필요, 트윅스는 비개발자도 직관적인 UI로 즉시 조정 가능
