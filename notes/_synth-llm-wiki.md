# LLM 위키 종합

## 핵심: 모든 노트가 동의하는 것

**LLM 위키 = AI가 읽고 판단하기 위해 구조화된 개인 지식 시스템**

사람이 읽는 일반 위키와 달리, AI가 활용할 수 있도록 최적화된 지식 베이스다. 안드레이 카파시(테슬라 AI 총괄 출신)가 제안한 개념으로, 단 하나의 트윗이 수천만 뷰를 기록하며 트렌드가 됐다. [[2026-05-22-Claude-Code보다-중요한-AI-OS-설계]] [[2026-06-05-UX-UI-디자이너에게-옵시디언이-필수가-되고-있는-이유]]

**문제 1: AI의 기억 상실**

### 🏗️ "어떻게 작동하는가" — 구조는 일관됨

모든 노트가 **3층 구조**에 동의한다:
- **로소스(Raw)**: 원본 자료 보관
- **위키(Wiki)**: AI가 핵심만 정리·연결한 요약본 (수시 갱신)
- **스키마/에이전트MD**: 운영 규칙·플레이북
