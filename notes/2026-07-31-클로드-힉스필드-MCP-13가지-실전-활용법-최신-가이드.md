# AI 영상 제작, 이 두개면 다 됩니다 | 클로드 + 힉스필드 MCP 13가지 실전 활용법 (최신 가이드)

## 🧠 이해 (Understand)
- **Summary:** 익스필드(PixsField)와 클로드 AI를 MCP로 연결하면 기획부터 이미지·영상·광고·웹페이지까지 하나의 흐름으로 제작할 수 있다. 핵심 워크플로우는 '기획(클로드) → 이미지 검토 → 영상 생성(익스필드 크레딧 소모)'으로, 비용과 시간을 줄이는 단계적 접근이 강조된다. 나만의 캐릭터(레퍼런스 시트)를 등록해 두면 매번 사진을 첨부하지 않아도 일관된 결과물을 얻을 수 있다. 클로드 스킬 5개(쇼츠 크리에이터·익스플레이너 스튜디오·애드 스크립터·애드 크리에이터·기타)를 등록하면 슬래시 명령 하나로 복잡한 프롬프팅을 대체할 수 있다. 결과물로 3D 애니메이션 쇼츠, 설명 영상, 광고 포스터+영상, 스크롤 애니메이션 웹페이지까지 제작 가능하며 5초 영상 1개 비용은 약 1,000원 수준이다.
- **Core Message:** 클로드 MCP와 익스필드를 연결하면 기획·이미지·영상·광고·웹페이지를 하나의 채팅 흐름 안에서 단계적으로, 저비용으로 제작할 수 있다.
> 딸각 한 번은 아니고 딸각 좀 여러 번을 해야 된다.
> AI를 잘 쓰려면 그 앞에서 기획하는 과정에 반드시 들어가야 돼요.
> 기획을 했으면은 영상으로 바로 직행하지 마시고, 이미지를 먼저 만들어 보는 거예요.
❗ 5초짜리 3D 애니메이션 영상 1개 제작 비용이 약 1,000원(15크레딧) 수준이다.
❗ 60초 설명 영상(나레이션+애니메이션 4클립) 전체 제작도 클로드 채팅 안에서 기획부터 완성까지 가능하다.
❗ 아기 영상 쇼츠 여러 편을 약 2,500원(45크레딧)으로 제작했다.

## 📚 핵심 용어
- **MCP (Model Context Protocol):** 클로드 같은 AI 모델과 외부 서비스(익스필드 등)를 실시간으로 연결해 주는 표준 연결 규격. / TV 리모컨처럼, 버튼(클로드 채팅) 하나로 다른 기기(익스필드)를 직접 조종할 수 있게 해주는 연결선이다. / API는 개발자가 코드로 연결해야 하지만, MCP는 설정 링크만 붙여 넣으면 비개발자도 AI끼리 바로 연동된다.
- **클로드 스킬:** 자주 쓰는 작업 흐름을 슬래시(/) 명령 하나로 실행할 수 있도록 등록해 둔 나만의 프롬프트 패키지. / 게임의 단축키 스킬처럼, 긴 주문을 매번 타이핑하지 않고 /스킬명 하나로 복잡한 작업을 즉시 불러쓴다. / 일반 프롬프트는 매번 직접 작성해야 하지만, 스킬은 한 번 등록하면 재사용 가능해 반복 작업 속도가 크게 빨라진다.
- **레퍼런스 시트:** 정면·측면 등 여러 각도의 인물 사진을 하나의 이미지에 모아 AI가 일관된 캐릭터를 생성하도록 만든 기준 시트. / 배우 캐스팅 프로필 사진처럼, AI가 '이 사람이 주인공'임을 기억하고 반복 등장시킬 수 있게 해주는 신분증이다. / 매번 사진을 첨부하는 방식과 달리, 레퍼런스 시트를 한 번 등록하면 이름만 언급해도 일관된 외모로 생성된다.
- **익스플레이너 스튜디오:** 주제 하나를 입력하면 기획·스토리보드·나레이션·3D 애니메이션 영상까지 자동으로 생성해 주는 설명 영상 제작 스킬. / 예전엔 외주 업체에 맡겨야 했던 과학·교육 유튜브 영상을, 궁금한 질문 한 줄로 뚝딱 만들어 주는 자동 PD다. / 일반 영상 생성은 장면 하나씩 지시해야 하지만, 익스플레이너 스튜디오는 주제만 주면 기획부터 완성까지 자동으로 처리한다.
