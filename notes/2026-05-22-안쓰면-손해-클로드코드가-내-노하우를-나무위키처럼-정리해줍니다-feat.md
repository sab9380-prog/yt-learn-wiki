## 🧠 이해 (Understand)
- **Summary:** 안드레 카파티(테슬라 AI 총괄, 오픈AI 창립멤버)가 공개한 LM 기반 나무위키 시스템을 소개하는 영상입니다. 이 시스템은 개인의 업무 노하우와 지식을 AI가 자동으로 위키 형태로 정리해주는 도구로, 3층 구조(로데이터-위키생성-스키마)로 작동합니다. 옵시디언과 클로드 코드를 활용하여 구축하며, 지식이 복리로 쌓이는 특징이 있습니다. 노트북LM이나 RAG 시스템과 달리 지식이 축적되고 상호 참조되어 점진적으로 발전하는 개인 지식베이스를 만들 수 있습니다.
- **Core Message:** 개인의 업무 노하우를 AI가 자동으로 위키화하여 지식이 복리로 쌓이는 개인 전용 나무위키 시스템을 구축할 수 있다.
> 지식이 복리로 쌓인다는 겁니다
> 우리는 단순히 내가 포함하고 싶은 로데이터만 잘 넣어주기만 하면 됩니다
> 개별 페이지에서는 보이지 않지만 여러 페이지를 겹쳐놓으면 드러나는 연결점
❗ 안드레 카파티는 테슬라 AI 총괄과 오픈AI 창립멤버를 역임한 AI 전문가
❗ 옵시디언 같은 도구는 교차 참조 작업이 수작업으로 매우 번거로웠지만, 이 시스템은 AI가 자동화
❗ 수십만 건 문서는 RAG 시스템이 적합하지만, 개인/소규모는 이 시스템이 더 효율적

## 📚 핵심 용어
- **LM 나무위키:** AI가 개인 자료를 읽어 나무위키 스타일로 자동 정리해주는 시스템 / 개인 비서가 내 모든 메모와 자료를 읽고 체계적인 백과사전을 만들어주는 것과 같다. / 노트북LM은 자료 검색 도구, LM 나무위키는 지식이 연결되어 성장하는 생태계. 단순 찾기 vs 축적.
- **지식 복리:** 새 정보가 추가될 때 기존 지식과 연결되어 시너지를 내는 현상 / 돈을 저금하면 이자가 붙어 늘어나듯, 지식도 쌓일수록 서로 연결되어 더 큰 인사이트를 만든다. / 일반 저장은 파일만 늘어남, 지식 복리는 기존 내용이 새 정보로 더 풍부해짐. 누적 vs 융합.
- **교차 참조:** 서로 다른 위키 페이지들 사이에 관련 키워드로 링크를 자동 연결하는 기능 / 도서관에서 한 책을 보다가 '관련 도서는 3층 경제학 코너'라는 안내를 보는 것처럼 연관 정보를 바로 찾게 해준다. / 수동 링크는 사람이 일일이 연결, 교차 참조는 AI가 내용 분석해서 자동 연결. 수작업 vs 지능형.
- **건강 검진 모드:** 위키 내용 중 모순되거나 오래된 정보를 찾아 수정 제안하는 기능 / 정기 건강검진으로 몸의 문제를 조기 발견하듯, 지식베이스의 오류나 낡은 정보를 점검해준다. / 수동 관리는 사람이 일일이 확인, 건강 검진은 AI가 자동으로 문제점 탐지. 방치 vs 예방.
