# (인건비 절약) AI 직원 자동화 방법, "이제 화면 녹화 던져주면 그대로 따라합니다." 클로드 코워크

## 🧠 이해 (Understand)
- **Summary:** 클로드 코워크(Claude desktop)의 레코더 스킬을 활용하면 업무 화면을 녹화하는 것만으로 AI에게 반복 업무를 학습시킬 수 있다. 녹화→학습→스킬 저장→반복 실행의 4단계 구조로, 코딩이나 복잡한 프롬프트 없이도 자동화가 가능하다. 실전 예시로 AI 피팅컷 다중 포즈 생성 자동화를 시연하며, 빌드업 스페이스에서 5가지 포즈를 AI가 혼자 처리하는 전 과정을 보여준다. 피팅컷 외에도 리뷰 댓글, CS 처리, 상품 등록, 네이버 광고 세팅 등 브라우저에서 하는 모든 업무에 적용 가능하다. 윈도우에서는 레코더 스킬 대신 영상 파일을 지정 폴더에 업로드해 학습시키는 방식으로 동일하게 구현된다.
- **Core Message:** 업무 화면을 녹화해 AI에게 보여주는 것만으로 반복 업무를 완전 자동화할 수 있는 시대가 열렸다.
> 얘는요, 딱 한 번만 배우면 안 까먹고요. 퇴사도 안 합니다.
> 영상은 과정을 가르치는 거고요. 프롬프트는 기준을 가르치는 겁니다.
> 자동화의 문턱이 녹화하기 버튼으로 엄청나게 낮아진 거예요.
❗ 맥 전용인 레코더 스킬을 윈도우에서도 영상 파일 업로드 방식으로 동일하게 구현할 수 있다.
❗ 피팅컷 기준 컷 1장만 만들면 나머지 다중 포즈 생성은 AI가 브라우저를 직접 조작해 전부 처리한다.
❗ 학습용 영상은 10분을 넘지 않아야 하며, 신입 교육처럼 또박또박 천천히 녹화할수록 학습 정확도가 높아진다.

## 📚 핵심 용어
- **레코더 스킬:** 업무 화면 녹화본을 AI에게 학습시켜 같은 업무를 자동 반복하게 만드는 클로드 코워크의 기능. / 신입 직원 옆에 앉아 '이 버튼 누르고, 여기 입력해'를 보여주면 그다음부터 혼자 하는 것과 같다. / 기존 자동화는 매뉴얼·코드를 따로 만들어야 했지만, 레코더 스킬은 녹화본 하나로 그 단계를 생략한다.
- **클로드 코워크:** 화면을 보고 마우스·키보드를 직접 조작하며 컴퓨터 업무를 수행하는 Claude의 데스크탑 에이전트. / AI가 내 모니터 앞에 앉아 손수 마우스를 움직이며 일을 처리하는 '보이지 않는 직원'과 같다. / 일반 Claude는 텍스트 답변만 하지만, 클로드 코워크는 실제 화면을 보고 클릭·입력까지 직접 실행한다.
- **클로드 스킬:** 학습된 업무 절차를 저장해두고 명령 한 마디로 재실행할 수 있는 클로드 코워크의 저장된 자동화 단위. / 엑셀 매크로처럼, 한 번 기록해두면 버튼 하나로 같은 작업을 언제든 다시 돌릴 수 있다. / 매크로는 고정된 좌표·순서만 반복하지만, 스킬은 AI가 상황을 보고 판단하며 유연하게 실행한다.
- **빌드업 스페이스:** AI 피팅컷 생성과 멀티포즈 변경 기능을 제공하는 패션 특화 AI 이미지 생성 서비스. / 모델 없이도 옷 사진 한 장을 올리면 다양한 포즈의 피팅컷을 자동으로 뽑아주는 온라인 스튜디오. / 일반 AI 이미지 생성툴은 매번 새 이미지를 만들지만, 빌드업 스페이스는 기준 이미지의 일관성을 유지한 채 포즈만 바꾼다.

## 🚀 실행 (Execute)
- [ ] 반복 중인 업무 1개를 골라 10분 이내로 또박또박 화면 녹화 후 클로드 코워크에 학습시켜 스킬로 저장하기 (피팅컷 포즈 변경 또는 리뷰 댓글 등 브라우저 기반 업무 우선) — ⏰ 이번 주 · ⚡ 2~3시간 (녹화 30분 + 학습 및 테스트 1~2시간)

  - 이유: 실제로 한 번 돌려봐야 어느 업무에 적합한지, 오류 패턴은 무엇인지 체감할 수 있고 즉시 시간 절감 효과가 발생한다.
- [ ] 상품 등록 자동화를 위해 '신상 등록' 폴더 구조(썸네일·상세페이지·정보 텍스트)를 표준화하고, 플랫폼별(하이버·네이버·에이블리 등) 등록 화면을 각각 녹화해 별도 스킬로 저장하기 — ⏰ 2주 내 · ⚡ 반나절~하루 (폴더 설계 1시간 + 플랫폼별 녹화 및 학습 각 30분)
  - 담당: 나 또는 팀원
  - 이유: 폴더 구조 표준화가 선행돼야 AI가 파일을 정확히 읽고 등록 자동화가 안정적으로 동작하며, 플랫폼별 스킬 분리로 오등록 사고를 방지할 수 있다.
- 자료: Claude for Desktop (claude.ai/download) — 클로드 코워크 공식 다운로드

- 자료: 클로드 코워크 레코더 스킬 공식 문서 — Anthropic 공식 블로그 또는 docs.anthropic.com에서 'computer use' / 'recorder skill' 검색
- Timeline: 1주 차: 브라우저 기반 반복 업무 1개 선정 → 녹화 → 스킬 저장 → 테스트 실행. 2주 차: 상품 등록 폴더 구조 표준화 + 플랫폼별 스킬 제작. 3~4주 차: 리뷰 댓글·CS 업무 스킬 추가 제작 및 전체 자동화 루틴 통합.
